# מגבלות תצורה

- **2MB** עבור מפות סיביות (bitmaps) — מפת סיביות אחת במסך מלא ב-X20 לבדה
  צורכת כ-768K.
- **2MB** עבור סקריפטים של Lua — תקציב נדיב למעשה.

!!! tip "מפות סיביות בסקריפטים"
    הימנעו מהחזקת כמויות גדולות של נתוני מפות סיביות ב-RAM. העדיפו **טעינה
    עצלה** (lazy loading) — טענו מפת סיביות רק כאשר היא נדרשת בפועל, ולאחר מכן
    שמרו אותה במטמון בזיכרון לפעם הבאה, במקום לקרוא אותה שוב ושוב מכרטיס
    ה-SD card/eMMC.
