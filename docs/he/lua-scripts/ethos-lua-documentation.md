# תיעוד Lua של Ethos

מדריך ה-API המלא של Lua ב-Ethos מצורף ל-**Ethos Suite**, תחת הלשונית
**Lua Development Tools** — זהו המקור המוסמך לכל קריאת API מסוג
`system.*`, `lcd.*` ואחרות הזמינות לסקריפט, והוא מסונכרן עם גרסת
Ethos שאיתה הוא מסופק.

ראו [Ethos Suite](../ethos-suite/index.md) להתקנה ולשימוש ביישום
המחשב עצמו.
