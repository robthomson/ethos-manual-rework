# מפרש Lua

Ethos כולל מפרש המבוסס על **Lua 5.4.3**, הארוז עם:

- הספרייה הבסיסית (basic)
- ספריית הטבלאות (table)
- ספריית io
- ספריית os
- ספריית math

סקריפטים פועלים בסביבה זו, בין אם הם מיישמים [ווידג'ט תצוגה](../displays/custom-widgets.md) ובין אם הם [מקור/משימה](../model-setup/lua-scripts.md) ברמת הדגם.
