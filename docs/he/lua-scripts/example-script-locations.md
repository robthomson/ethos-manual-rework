# מיקומי סקריפטים לדוגמה

סקריפטים רשמיים לדוגמה מפורסמים בכתובת
[github.com/FrSkyRC/ETHOS-Feedback-Community](https://github.com/FrSkyRC/ETHOS-Feedback-Community/tree/main/lua)
(בפרט `/lua/examples/task` ו-`/lua/examples/source`). מרבית
הדוגמאות הן ווידג'טים של Lua (מוגדרים תחת [הגדרת
מסכים](../displays/custom-widgets.md)); הדוגמה **`servo`**
מדגימה באופן ספציפי **כלי מערכת** — סקריפט המופיע לאחר
**Info** בתפריט המערכת ולא כווידג'ט תצוגה.

## הורדת סקריפט

1. פתחו את קישור המאגר שלמעלה בדפדפן ונווטו לתיקייה, ולאחר מכן לקובץ
   `main.lua` הרצוי.
2. לחצו על הקובץ כדי להציג אותו, ולאחר מכן על **Raw**.
3. לחצו לחיצה ימנית על הדף → **Save Page as…**, ושמרו אותו בשם `main.lua`.
4. כדי למנוע התנגשות עם קובצי `main.lua` של סקריפטים אחרים, העבירו אותו
   לתיקייה בעלת שם מתאים — שם תיקיית המקור עצמה הוא בחירה הגיונית.

עבור כל קובץ אחר שהסקריפט זקוק לו (תמונות וכדומה): לחצו על הקובץ, לחצו על
**Download**, ולאחר מכן לחצו לחיצה ימנית ובחרו **Save Image as…** (או שקול לכך) כדי
לשמור אותו לצד הסקריפט.

סקריפטים מותקנים תחת `scripts/` בכרטיס ה-SD/eMMC — ראו [מנהל
הקבצים](../system-setup/file-manager.md#top-level-folders).

ראו גם את השרשור *FrSky ETHOS Lua Script Programming* באתר rcgroups לסקריפטים
של הקהילה ולדיונים מעבר לדוגמאות הרשמיות.
