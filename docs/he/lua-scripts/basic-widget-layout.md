# מבנה בסיסי של ווידג'ט

ווידג'ט Lua מותאם אישית (ראה [ווידג'טים מותאמים אישית](../displays/custom-widgets.md)
להתקנה של אחד כזה) נבנה מקבוצה קטנה של שדות/מטפלים בעלי שם:

- **`key`** *(מחרוזת)* — מזהה ייחודי לווידג'ט.
- **`name`** *(מחרוזת או פונקציה)* — שם התצוגה של הווידג'ט. או מחרוזת
  פשוטה, או פונקציה שאינה מקבלת ארגומנטים ומחזירה מחרוזת — שימושי עבור
  שם המשתנה בהתאם לשפה.
- **`create`** *(פונקציה)* — נקראת פעם אחת בעת יצירת הווידג'ט,
  ואינה מקבלת ארגומנטים. מחזירה **טבלת ווידג'ט**, המועברת לאחר מכן
  לכל אחד מהמטפלים האחרים שלהלן — כאן יש לאתחל את המצב (state) ולשמור אותו
  בטבלה זו.
- **`configure`** *(פונקציה)* — נקראת כאשר המשתמש פותח את מסך ההגדרות של
  הווידג'ט, ומקבלת את טבלת הווידג'ט מ-`create()` כארגומנט היחיד שלה,
  ואינה מחזירה דבר. כאן יש לבנות את טופס ההגדרות ולהשתמש בו לעדכון
  ערכים בטבלת הווידג'ט.
- **`wakeup`** *(פונקציה)* — נקראת בכל מחזור (בקירוב כל 50 מילישניות),
  מקבלת את טבלת הווידג'ט ואינה מחזירה דבר. כאן יש לבדוק אם משהו
  השתנה; אם כן, קרא ל-`invalidateWindow()` כדי להפעיל ציור מחדש דרך
  `paint()`. שמור על מטפל זה מהיר — באופן אידיאלי הוא לא יעשה דבר ברוב
  הפעמים שבהן הוא נקרא.
- **`event`** *(פונקציה)* — נקראת כאשר הווידג'ט מקבל אירוע;
  Ethos מנתב אירועים שרירותיים לווידג'ט דרך מטפל זה.
- **`paint`** *(פונקציה)* — מציירת את הווידג'ט, מקבלת את טבלת הווידג'ט
  ואינה מחזירה דבר. נקראת אוטומטית בכל פעם שהופעל `lcd.invalidate()`.
  יכולה להיות איטית יחסית, אך עדיין כדאי שתצייר מחדש בפועל רק כאשר
  משהו השתנה.
- **`read`** *(פונקציה, אופציונלי)* — קוראת את אחסון הווידג'ט המתמיד.
- **`write`** *(פונקציה, אופציונלי)* — כותבת לאחסון הווידג'ט המתמיד.
- **`init`** *(פונקציה)* — רושמת את הווידג'ט ואת פונקציות ההחזרה שלו
  ב-Ethos. בדרך כלל הדבר האחרון בסקריפט:

```lua
local function init()
  system.registerWidget({
    key = "unique",
    name = name,
    create = create,
    configure = configure,
    wakeup = wakeup,
    paint = paint,
    read = read,
    write = write,
  })
end

return { init = init }
```

`key` חייב להיות ייחודי בין כל הווידג'טים המותקנים; שאר השדות משתלבים
במחזור החיים של הווידג'ט כמתואר לעיל.

הסקריפטים נמצאים תחת `scripts/` ב-SD card/eMMC, ורצוי שיהיו מסודרים
בתיקיות נפרדות לכל ווידג'ט (ראה [מנהל
הקבצים](../system-setup/file-manager.md#top-level-folders) ו-[מיקומים
לדוגמה של סקריפטים](example-script-locations.md)). לדוגמאות מעשיות
נוספות ראה את השרשור *FrSky ETHOS Lua Script Programming* באתר rcgroups.
