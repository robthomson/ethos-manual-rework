# תחילת העבודה

לפני שצוללים אל הגדרות הדגם או המערכת, כדאי להתרגל לשני הדברים שתשתמשו בהם ללא הרף: [המסך
הראשי](main-views.md) ו[מודל
הניווט](user-interface-and-navigation.md) עצמו (המסובב, מקשי
`ENT`/`RTN` והמגע).

- [תצוגות ראשיות](main-views.md) — מסך הבית ותפריט חיבור ה-USB.
- [ממשק משתמש וניווט](user-interface-and-navigation.md) — עריכת
  ערכים, המקלדת שעל המסך, וכיצד נבחר "מקור" בכל רחבי
  Ethos.
- [מצבי חיבור USB](usb-connection-modes.md) — מה משתנה כאשר
  המשדר מחובר למחשב.
- [מצב חירום](emergency-mode.md) — מה קורה אם משהו משתבש
  ברמה נמוכה בצורה חמורה.
