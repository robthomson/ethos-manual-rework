# רשימת בדיקה עם טקסט מוגדר על ידי המשתמש

![טקסט רשימת בדיקה של המשתמש](../assets/model-checklist-user-checklist.png)

פונקציית [רשימת בדיקה](../model-setup/checklist.md) יכולה להציג טקסט מותאם אישית
בעת ההפעלה — טקסט פשוט או טקסט בעיצוב Markdown — באופן אוטומטי,
בכל פעם שהדגם נטען.

## 1. יצירת טקסט רשימת הבדיקה

**טקסט פשוט** — כתבו אותו בכל עורך טקסט (Notepad++, או אפילו MS
Word בשמירה כטקסט פשוט) ושמרו בשם `<model name>.txt`.

**טקסט משופר (Markdown)** — Ethos תומך בעיצוב Markdown, לדוגמה
`##` לכותרת, `**bold**` לטקסט מודגש. השתמשו בכל עורך טקסט
(עם הזנת תחביר Markdown באופן ידני) או בעורך Markdown מיוחד
(Nextpad, MarkText וכדומה), ושמרו בשם `<model name>.md`.

```markdown
## Emphasis
**this is bold text**
*this is italic text*
```

## 2. העתקה למשדר

העתיקו את הקובץ לאותה תיקיית `models/` שבה נמצא קובץ ה-`.bin`
של הדגם עצמו (ראו [מנהל הקבצים](../system-setup/file-manager.md#top-level-folders)),
ולאחר מכן הוציאו את כונני המשדר בצורה בטוחה לפני ניתוקם.

## 3. בדיקה

טענו את הדגם — טקסט רשימת הבדיקה מופיע כעת כחלק מבדיקות ההפעלה
באופן אוטומטי, וניתן לגלול בו אם הוא ארוך ממסך אחד.
