# הגדרת מערכת FBUS

[FBUS](../model-setup/telemetry.md#how-frsky-telemetry-works) (בעבר
F.Port2) מעביר שליטה וטלמטריה על גבי קו אחד, ומאפשר לכמה התקני FBUS
לחלוק חיבור שרשרת (daisy-chain) יחיד עם אפשרות להגדרה מלאה באופן אלחוטי. מדריך זה מחבר שני
סרוו Xact לערוצי המאזנים (1 ו‑5) של [דוגמת כנף קבועה
בסיסית](../tutorials/basic-fixed-wing.md).

!!! note "צילומי מסך בהמתנה"
    לעמוד זה אין עדיין צילומי מסך מהסימולטור — ראה [תהליך צילומי
    המסך](../contributing/screenshot-pipeline.md).

## 1. הורדת הקושחה העדכנית

FBUS דורש קושחה עדכנית גם במקלט וגם בהתקנים — לדוגמה, סרוו Xact דורשים
גרסה v2.0.1 ומעלה. הורד את העדכונים הרלוונטיים מ[עמוד ההורדות של
FrSky](https://www.frsky-rc.com/download/).

## 2. צריבת הקושחה

העתק את קובצי הקושחה לתיקייה `Firmware/` בכרטיס SD card/eMMC. ב[מנהל
הקבצים](../system-setup/file-manager.md), חבר את הסרוו למחבר S.Port של
המשדר (החוט הלבן/צהוב לכיוון החריץ), בחר את קובץ הקושחה, ולחץ
**Flash External Device** (צריבת התקן חיצוני).

## 3 / 5. הגדרת מזהים פיזיים (Physical ID)

שני הסרוו מוגדרים כברירת מחדל למזהה פיזי `0C` הקסדצימלי / מזהה יישום
`6800` הקסדצימלי — הם יתנגשו על האפיק המשותף אלא אם אחד מהם ישונה. ישנן שתי
דרכים לעשות זאת, בהתאם לסוג המקלט:

**באמצעות מחבר ה‑S.Port של המשדר** (כל מקלט):

1. חבר את סרוו 1, עבור אל **Device Config → XAct**, והגדר את **Module** ל‑
   **S.Port connector**. השאר את המזהה הפיזי `0C`/מזהה היישום `6800` ואת
   הערוץ `CH1` בברירת המחדל, ולאחר מכן **Save to flash**.
2. חבר את סרוו 2 במקומו, באותו תפריט. שנה את **Physical ID** ל‑`0D`
   הקסדצימלי ואת **Application ID** ל‑`6801` הקסדצימלי (ראה [טבלת המזהים
   הפיזיים](../model-setup/telemetry.md#how-frsky-telemetry-works) כדי
   לדעת אילו מקומות פנויים), הגדר את **Channel** ל‑`CH5`, ולאחר מכן
   **Save to flash**.

**באמצעות המקלט ישירות** (לדוגמה TD-R18 Tandem, כששני הסרוו מחוברים
בו‑זמנית — ראה [שלב 4](#4-configure-the-receiver-for-fbus)):

1. כאשר רק סרוו 1 מחובר (למשל ל‑Pin1 של המקלט), **Device Config →
   XAct**, **Module** → **Internal module**. אשר את ברירות המחדל (`0C`/
   `6800`/`CH1`), ולאחר מכן **Save to flash**.
2. כאשר רק סרוו 2 מחובר (Pin5), באותו תפריט (Device Config מתקשר עם סרוו
   אחד בכל פעם) — שנה ל‑`0D`/`6801`/`CH5`, ולאחר מכן **Save to flash**.
   בחר שוב ב‑Device Config לאחר מכן כדי לאמת שהשינוי נשמר.

## 4. הגדרת המקלט לעבודה עם FBUS {: #4-configure-the-receiver-for-fbus }

**SR10 Pro**: [מערכת RF](../model-setup/rf-system.md) → לחצן המקלט →
**Options** → הגדר את **Telemetry Port** ל‑**FBUS**. סרוו Xact מתחברים
לאחר מכן בשרשרת מאותה יציאה; מכיוון שלכל סרוו יש מחבר אחד בלבד, מפצל
רב‑ערוצי של F.Port2 ‏(FP2CH4/6/8) מפצל אותו לכמה חיבורים.

**TD-R18 Tandem**: מערכת RF → לחצן המקלט → **Options** → הגדר פינים
בודדים (למשל **Pin1**, **Pin5**) ל‑**FBUS** — ניתן להקצות מחדש בדרך זו
כמה פינים שנדרש, וכך להימנע לחלוטין מהצורך במפצלים; כל פין שהוגדר
כ‑FBUS נושא אות FBUS זהה.

## 5. בדיקת השליטה בסרוו דרך FBUS

חבר את סרוו 1 ל‑Pin1, את סרוו 2 ל‑Pin5 (ערוצי המאזנים של דוגמת הכנף
הקבועה), הפעל את המערכת, ואמת שערוצים 1 ו‑5 מזיזים את הסרוו הנכונים.

## 6. בדיקת טלמטריית FBUS

כאשר שני הסרוו מחוברים, מחק חיישני `SRV` קיימים תחת
[טלמטריה](../model-setup/telemetry.md) ובצע גילוי מחדש. כל סרוו מדווח על
4 חיישנים: זרם, מתח, טמפרטורה ומצב (`OK` כאשר הכול תקין).

## 7. ביצוע שינויי הגדרות בהמשך

לאחר שהדגם מחובר במלואו, בידוד של סרוו יחיד כדי להגדירו מחדש דרך
Device Config אינו מעשי. במקום זאת: עבור אל טלמטריה, מצא חיישן השייך
לסרוו הרצוי (למשל `SRV1 curr`), ובחר **Configure** — פעולה זו פותחת
ישירות את ההגדרות של אותו סרוו. לחץ **Save to flash** לאחר כל שינוי.

!!! warning
    היזהר לא לשנות בטעות את המזהה הפיזי או את מזהה היישום ממסך זה — אלה
    הם שמאפשרים לפנות לכל סרוו בנפרד על האפיק המשותף.
