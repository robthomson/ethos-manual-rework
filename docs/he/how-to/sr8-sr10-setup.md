# הגדרת דגם עבור SR8/SR10 וסידור מחדש של ערוצים

מקלטי הייצוב מסדרת SRx של FrSky מצפים לסדר ערוצים מסוים. קיימים שני
תרחישים: בניית דגם חדש עבורם מאפס, או המרת דגם קיים כך שיתאים.

!!! note "צילומי מסך בהמתנה"
    בעמוד זה אין עדיין צילומי מסך מהסימולטור — ראו [Screenshot
    Pipeline](../contributing/screenshot-pipeline.md).

## יצירת דגם חדש

אשף [בחירת דגם](../model-setup/model-select.md) מקבץ כברירת מחדל משטחי
היגוי בעלי אותה פונקציה (לדוגמה, 2 מאזנים → `AAETR`), אך מקלטי SRx
דורשים שארבעת הערוצים הראשונים יהיו קבועים בסדר **AETRA** במקום זאת.

1. במסך [Controls](../system-setup/controls.md), ודאו שההגדרה **Channel order**
   היא `AETR`.
2. הפעילו את **[First four channels
   fixed](../system-setup/controls.md#first-four-channels-fixed)** — הגדרה זו
   מונעת מהאשף לקבץ את ארבעת הערוצים הראשונים, ומשאירה אותם בסדר
   `AETRA…` מדויק, ללא תלות במספר משטחי ההיגוי מכל סוג שקיימים בדגם.
3. הפעילו את אשף יצירת הדגם כרגיל — 5 הערוצים הראשונים יתקבלו בסדר `AETRA`.

!!! note "בדיקה עצמית של מקלטי Archer"
    בדיקה עצמית עבור מקלטי Archer מתבצעת כיום דרך [Device Config →
    SxR](../system-setup/devices.md) (גרסת קושחה v2.1.10 ומעלה), ולא באמצעות
    הליך בדיקה עצמית נפרד. ערוץ המצערת חייב להיות במצב
    ‎−100%‎, אחרת הבדיקה העצמית לא תתחיל.

## סידור מחדש של דגם קיים

המרת דגם קיים (לדוגמה, `AAETRFF` כיום) לסדר הנדרש עבור מקלטי הייצוב
(`AETRAE`, ולאחר מכן ערוץ 9 להגבר (Gain), 10/11 למצבי טיסה,
ו-12 לבדיקה עצמית ביחידות SxR ותיקות) מתבצעת באמצעות סדרה של החלפות ערוצים
במסך [יציאות](../model-setup/outputs.md#swap-channels).

נקודת הפתיחה:

| ערוץ | פונקציה |
|---|---|
| 1 | מאזן 1 (ימני) |
| 2 | מאזן 2 (שמאלי) |
| 3 | מעלית |
| 4 | מצערת |
| 5 | הגה כיוון |
| 6 | מדף 1 (ימני) |
| 7 | מדף 2 (שמאלי) |
| 8 | כן נסע מתקפל |

הסדר הנדרש: `AETRAE` — ערוץ 1 מאזן 1, ערוץ 2 מעלית, ערוץ 3 מצערת,
ערוץ 4 הגה כיוון, ערוץ 5 מאזן 2, ערוץ 6 מעלית 2/AUX2 (ולאחר מכן
הגבר/מצבי טיסה/בדיקה עצמית בערוצים 9–12).

1. **תחילה יש לפנות את מאזן 2 מדרכו**: במסך יציאות, בחרו את CH2
   (מאזן 2), הקישו שוב, בחרו **Swap Channels**, והחליפו אותו עם ערוץ
   שאינו בשימוש (לדוגמה CH9). ההחלפה מתבצעת מיד — כל מיקס שמתייחס לאחד
   מהערוצים מתעדכן אוטומטית.
2. **החליפו את CH3 (מעלית) → CH2.**
3. **החליפו את CH4 (מצערת) → CH3.**
4. **החליפו את CH5 (הגה כיוון) → CH4.**
5. **החליפו את CH9 (מאזן 2, שהוחנה שם בשלב 1) → CH5.**

התוצאה:

| ערוץ | פונקציה |
|---|---|
| 1 | מאזן 1 (ימני) |
| 2 | מעלית |
| 3 | מצערת |
| 4 | הגה כיוון |
| 5 | מאזן 2 (שמאלי) |
| 6 | מדף 1 (ימני) |
| 7 | מדף 2 (שמאלי) |
| 8 | כן נסע מתקפל |

— כעת בסדר שמקלטי הייצוב של FrSky מצפים לו.
