# ווידג'טים מותאמים אישית

מעבר [לסוגי הווידג'טים המובנים](index.md), סקריפטים של Lua יכולים לממש
ווידג'טים מותאמים אישית לחלוטין — בדרך כלל קובץ `main.lua` בודד המוחזק
בתיקיית משנה הנקראת בשם הפעולה שהוא מבצע.

## התקנה

העתיקו את תיקיית המשנה של הווידג'ט אל `scripts/` בכרטיס SD card/eMMC (ראו
[מנהל קבצים](../system-setup/file-manager.md#top-level-folders)). הווידג'ט
נרשם אוטומטית בהפעלה הבאה, ומאותו רגע מופיע בבורר הקטגוריות **החלפת ווידג'ט**
במסך [הגדרת מסכים](additional-displays.md) לצד הסוגים המובנים — ומוגדר
בדיוק באותה דרך.

## כתיבת ווידג'ט

ראו [סקריפטים של Lua → מבנה בסיסי של ווידג'ט](../lua-scripts/basic-widget-layout.md)
לקבלת מבנה הקוד שסקריפט ווידג'ט צריך לממש.
