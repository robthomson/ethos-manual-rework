# הגדרות דגם

כל מה שנמצא בפרק זה נשמר **עבור כל דגם בנפרד** — מעבר בין דגמים מחליף את כל ההגדרות הללו. כאן מתבצעת בפועל התכנות של דגם, מבחירת תבנית מסגרת אווירית ועד למיקסים, ליציאות ולמתגי הבטיחות שלו. הגישה היא דרך הלשונית **מטוס** בסרגל התחתון (או באמצעות המקש `MDL`) — בשונה מ[הגדרות מערכת](../system-setup/index.md), העוסקות בכל מה שמשותף לכל הדגמים.

- [בחירת דגם](model-select.md) — יצירה, בחירה וארגון של דגמים.
- [עריכת דגם](model-edit.md) — השם, הסוג והסמל של הדגם עצמו.
- [מצבי טיסה](flight-modes.md)
- [מיקסים](mixes.md) — ליבת תכנות הדגם.
- [יציאות](outputs.md) — נקודות קצה של סרוו/מנוע, סאב-טרים והיפוך כיוון.
- [טיימרים](timers.md)
- [טרימים](trims.md)
- [מערכת RF](rf-system.md) — קישור מקלט והגדרת מודול RF.
- [עקומות](curves.md)
- [מתגים לוגיים](logical-switches.md)
- [פונקציות מיוחדות](special-functions.md)
- [משתנים](variables.md)
- [מאמן](trainer.md)
- [טלמטריה](telemetry.md) — גילוי חיישנים וחיישנים מחושבים.
- [רשימת בדיקה](checklist.md)
- [סקריפטים של Lua](lua-scripts.md) — סקריפטים ופונקציות Lua ברמת הדגם.
