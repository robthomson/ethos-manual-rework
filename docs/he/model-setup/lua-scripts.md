# סקריפטים של Lua (דגם)

![Lua config](../assets/model-lua-config.png)

תפריט זה מופיע רק לאחר שהותקן סקריפט **source** או **task** של Lua בתיקייה `scripts/` שב-SD card/eMMC (ראה [מנהל קבצים](../system-setup/file-manager.md#top-level-folders)) — הוא מיועד להפעלה ולהגדרה של סקריפטים אלה **עבור כל דגם בנפרד**, ולא להתקנתם. לאחר ההתקנה, source או task זמינים באופן גלובלי לכל הדגמים; בעמוד זה כל דגם בוחר להשתמש בהם ומגדיר את התצורה שלו. דוגמאות לסקריפטי source ו-task מפורסמות באתר Ethos-Feedback-Community (`/lua/examples/task`, `/lua/examples/source`).

## משימות Lua

כל משימה מותקנת מופיעה ברשימה עם מתג הפעלה נפרד לכל דגם. הפעלת משימה חושפת את טופס ההגדרות שלה (אם קיים) — סקריפט המשימה מספק פונקציות קריאה/כתיבה משלו, כך שכל דגם יכול לשמור את ההגדרות שלו. לדוגמה, משימה עשויה להציע טווח מספרי הניתן להגדרה באופן עצמאי לכל דגם.

## מקורות Lua

אותה שיטה חלה על מקורות: הפעלה עבור כל דגם, ולאחר מכן הגדרה באמצעות הטופס שסקריפט המקור מספק. מקור שנרשם בדרך זו הופך לשמיש כ[מקור](../getting-started/user-interface-and-navigation.md#choosing-a-source) רגיל בכל מקום אחר ב-Ethos, בדיוק כמו מקור מובנה.

## למחברי סקריפטים

מקורות ומשימות נרשמים מתוך Lua באמצעות `system.registerSource()` ו-`system.registerTask()` — ראה את Ethos Lua Reference Guide, ואת [סקריפטים של Lua](../lua-scripts/index.md) במדריך זה עבור סביבת הסקריפטים הכללית (ווידג'טים הם מנגנון נפרד וקשור — ראה [ווידג'טים מותאמים אישית](../displays/custom-widgets.md)).
