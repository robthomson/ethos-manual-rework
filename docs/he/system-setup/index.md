# הגדרות מערכת

הגדרות מערכת מגדירות את חלקי המשדר המשותפים לכל דגם — הגישה אליהן דרך לשונית **גלגל השיניים** בשורה התחתונה (או באמצעות המקש `SYS`). כל מה שייחודי לדגם מסוים נמצא תחת [הגדרות דגם](../model-setup/index.md) (לשונית **המטוס** / המקש `MDL`) — ובמיוחד, בחירת מודול ה-RF שהדגם משתמש בו (פנימי או חיצוני) היא הגדרה ברמת הדגם תחת [RF System](../model-setup/rf-system.md), ולא כאן.

גע באריח כדי לפתוח אותו, או הזז את ההדגשה באמצעות הבורר המסתובב ולחץ `ENT`. קיים עמוד שני של אריחים — החלק שמאלה, הזז את ההדגשה אליו, או לחץ `PAGE` כדי לעבור.

- [מנהל הקבצים](file-manager.md) — קבצים ותיקיות, וצריבת קושחה למודול ה-RF הפנימי, להתקני S.Port, OTA ולמודולים חיצוניים.
- [התראות](alerts.md) — מצב שקט, סוללת המשדר/סוללת ה-RTC, התנגשות חיישנים והתראות חוסר פעילות.
- [תאריך ושעה](date-and-time.md) — שעון המערכת ואופן הצגתו.
- [כללי](general.md) — שפה, תצוגה, שמע, וריו, רטט, סרגל הכלים העליון, הדגם בעת ההדלקה ובחירה מוקדמת של מצב USB.
- [סוללה](battery.md) — ניהול סוללת המשדר.
- [חומרה](hardware.md) — בדיקה וכיול של הבקרים הפיזיים, הגדרת סוגי מתגים ומפת מקשי הבית.
- [בקרים](controls.md) — מצב הג'ויסטיקים וסדר הערוצים כברירת מחדל (נקרא "Sticks" בתפריט).
- [התקנים](devices.md) — חיישנים, מקלטים, מערכת הדלק (gas suite), סרוואים ומשדרי וידאו (נקרא "Device config" בתפריט).
- [מידע](information.md) — גרסת הקושחה, סוגי הגימבלים, מידע על מודול ה-RF, זמן פעולה ויומני שגיאות.
