# חומרה

![בדיקת חומרה](../assets/system-hardware-check-x20s.png)

בדיקה וכיול של אמצעי הבקרה הפיזיים של המשדר, הגדרת סוגי המתגים ומיפוי מקשי הבית.

## בדיקת חומרה {: #hardware-check }

מפעילה כל אחד מהכניסות הפיזיות כדי שתוכל לוודא שכל אחת מהן נרשמת כראוי.

![בדיקת חומרה X20 Pro](../assets/system-hardware-check-x20pro.png)
![בדיקת חומרה X18S](../assets/system-hardware-check-x18s.png)

- **X20 Pro/R/RS** — בודק גם את שני מתגי הלחיצה הננעלים **K** ו-**L** שבכתפיים האחוריות, וכן את הטרימים הנוספים **T5**/**T6**.
- **X18** — בודק גם את הטרימים הנוספים **T5**/**T6**.

## כיול אנלוגיים {: #analogs-calibration }

![כיול אנלוגי](../assets/system-hardware-analogs-calibration.png)

מלמד את המשדר בדיוק היכן נמצאים המרכז והגבולות של כל ג'ימבל, פוטנציומטר ומחוון. מתבצע אוטומטית בהפעלה הראשונה; חזור עליו לאחר החלפת ג'ימבל, פוטנציומטר או מחוון.

## כיול הגירוסקופ

![כיול גירוסקופ](../assets/system-hardware-gyro-calibration.png)

מכייל את הגירוסקופ המשולב כך שכניסות המבוססות על הטיה יגיבו נכון להטיית המשדר — מצב ה"מפולס" הופך להיות האופן שבו אתה מחזיק את המשדר בדרך כלל. גם כיול זה מתבצע אוטומטית בהפעלה הראשונה.

## מסנן אנלוגיים

מסנן ADC בהפעלה/כיבוי עבור הג'ויסטיקים, מופעל כברירת מחדל — מקטין רעידות סביב מרכז הג'ויסטיק. זו ההגדרה **הגלובלית**; קיימת גם עקיפה **לכל דגם** של מסנן האנלוגיים תחת [עריכת דגם](../model-setup/model-edit.md).

## הגדרות פוטנציומטרים/מחוונים {: #potssliders-settings }

שינוי שמות הפוטנציומטרים והמחוונים. דגמי **X20 Pro/R/RS** תומכים בנוסף בשני פוטנציומטרים נוספים, **Ext1**/**Ext2**, המשמשים בדרך כלל לג'ימבלים בעלי 3 צירים.

![ערכי ADC, פוטנציומטרים](../assets/system-hardware-pots-x20s.png)
![ערכי ADC, פוטנציומטרים (X20 Pro)](../assets/system-hardware-pots-x20pro.png)

## הגדרות מתגים {: #switches-settings }

![מתגים](../assets/system-hardware-switches.png)

- **השהיית זיהוי מרכז המתג** — מונעת ממעבר מהיר למעלה→למטה (או למטה→למעלה) של מתג תלת-מצבי להירשם לרגע במצב האמצעי; המצב האמצעי אמור להירשם רק כאשר המתג באמת נעצר שם. ברירת המחדל היא 0ms, שנבחרה כדי להתאים לזיהוי ה"בדיקה העצמית" של מקלטי FrSky המיוצבים בערוץ CH12.
- **סוג מתג** — כל אחד מהמתגים SA–SJ יכול להיות מוגדר כ-**None**, **Momentary**, **2 POS** או **3 POS**, מה שמאפשר להחליף פונקציונליות בין מתגים פיזיים (לדוגמה, להעניק למתג הרגעי SH את התפקיד שממלא בדרך כלל המתג הדו-מצבי SF) — בכפוף למה שחיווט המשדר אכן תומך בו (תפקיד תלת-מצבי בדרך כלל אינו יכול להיות מוקצה לחומרה שאינה מחווטת לכך).

  ![אפשרויות מתג](../assets/system-hardware-switches-options.png)
  ![מתגים נוספים](../assets/system-hardware-switches-2.png)

- **שינוי שם** — ניתן לשנות את שמות המתגים מ-SA–SJ לשמות מותאמים אישית; השמות גלובליים לכל הדגמים.
- **X20 Pro** — מוסיף את מתגי הלחיצה **K**/**L** בכתפיים האחוריות, וכן את המצבים **M**/**N** אם הם מחווטים (בדרך כלל למתגים בקצות הג'ויסטיקים).

## מיפוי מקשי בית

מגדיר מחדש לאן קופצים מקשי הבית `SYS`, `MDL` ו-`DISP` (`TELE` במשדרים ותיקים).

- **`DISP`** — הן לחיצה קצרה והן לחיצה ארוכה יכולות להיות מוגדרות מחדש לכל עמוד דגם, עמוד מערכת, הגדרת מסכים, בית או רשומת נתוני הטיסה. לצורך עקביות עם סדרת X10, לחיצה ארוכה על `DISP` מוגדרת בדרך כלל להגדרת מסכים.
- **`SYS`/`MDL`** — רק הלחיצה הארוכה ניתנת להגדרה מחדש (לאותה קבוצת יעדים); לחיצה קצרה פותחת תמיד את מקטע המערכת או הדגם, בהתאמה.

## אפשרויות חומרה ייחודיות למשדר {: #radio-specific-hardware-options }

- **הפעלת שדרוגי ג'ימבל הפטי** (X20 Pro, X20R) — דגמי X20 Pro AW ו-X20RS מסופקים עם ג'ימבלים מסוג MC20R הכוללים מנועי רעידה לג'ויסטיק; אם ג'ימבלי MC20R הותקנו בדיעבד ב-X20 Pro או ב-X20R, הפעל אותם כאן (ראה [פונקציות מיוחדות](../model-setup/special-functions.md) להגדרת תבניות הרעידה עצמן).

  ![הפטי (X20 Pro)](../assets/system-hardware-haptic-x20pro.png)
  ![הפטי (X20 Pro AW)](../assets/system-hardware-haptic-x20proaw.png)

- **אפשרות מקודד** (X20 Pro AW, X20R/RS) — משדרים אלה כוללים מקודד סיבובי רגיש יותר; הפעל **חצאי צעדים** כדי למתן אותו.

  ![אפשרות מקודד (X20 Pro AW)](../assets/system-hardware-x20proaw-encoder-option.png)

## בוחן ערכי ADC {: #adc-value-inspector }

מציג את ערכי ההמרה מאנלוגי לדיגיטלי הגולמיים שהמעבד קורא עבור כל כניסה אנלוגית:

![בדיקת ADC (X20S)](../assets/system-hardware-adc-check-x20s.png)
![בדיקת ADC (X20 Pro)](../assets/system-hardware-adc-check-x20pro.png)

**X20S**: 1 ג'ויסטיק שמאלי אופקי, 2 ג'ויסטיק שמאלי אנכי, 3 ג'ויסטיק ימני אנכי, 4 ג'ויסטיק ימני אופקי, 5 פוטנציומטר 1, 6 פוטנציומטר 2, 7 מחוון אמצעי, 8 מחוון שמאלי, 9 מחוון ימני.

**X20 Pro**: כמו לעיל, אך עם שני ערוצי פוטנציומטר חיצוני נוספים (7 Ext1, 8 Ext2 — לדוגמה פוטנציומטרים המורכבים על הג'ויסטיקים) המשולבים לפני המחוונים, אשר נעים ל-9 מחוון אמצעי, 10 מחוון שמאלי, 11 מחוון ימני.
