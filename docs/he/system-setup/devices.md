# התקנים

![התקנים](../assets/system-devices.png)

בתפריט נקרא **Device config** — כלים להגדרת התקנים היקפיים המחוברים דרך
S.Port/FBUS: חיישנים, מקלטים, ה-"gas suite", סרוואים, VTX ו-ESC. הפריט
**DIY sensors** מופיע אוטומטית ברגע שמזוהה חיישן DIY. לפרטים מלאים יש לעיין
במדריך של כל התקן; דף זה מכסה את המשותף לכולם.

!!! note
    אין לכך קשר לבחירת מודול ה-RF (הפנימי או החיצוני) שדרכו *דגם* משדר — זו
    הגדרה ברמת הדגם, המתוארת ב-[מערכת RF](../model-setup/rf-system.md).

Device Config הוא מודול הרחבה: גם משתמשים וגם FrSky יכולים להוסיף כאן דפים
באמצעות Lua.

## הקצאה מחדש של מזהי חיישנים

מסכי Device config של Ethos מאפשרים לשנות ישירות את **Physical ID** ואת
**Application ID** של התקן ב-S.Port. אם ברשותך יותר מהתקן אחד בעל אותה
פונקציה, חבר אותם **אחד בכל פעם**: זהה כל אחד ב-[טלמטריה → Discover new
sensors](../model-setup/telemetry.md), שנה את ה-Physical ID וה-Application ID
שלו כאן ב-Device config, ולאחר מכן חזור וזהה אותו מחדש תחת המזהה החדש.

## דוגמה: מקלטים

![בחירת מודול](../assets/system-devices-module-choice.png)

ניתן להגדיר כאן מקלטים מיוצבים של FrSky לאחר התקנת סקריפט ההגדרה שלהם ב-Lua
(בלחיצה אחת, מספריית ה-Lua של Ethos Suite). קיימים שני מסלולי הגדרה, בהתאם
לדור המקלט:

- **Stabilizer config** — מקלטים חדשים יותר עם "ייצוב מתקדם" (בקרת gain
  בערוץ 13). נחשפות שתי קבוצות ייצוב עצמאיות: קבוצה 1 מכסה ערוצים 1–6,
  קבוצה 2 מכסה 7–11 — כבה את קבוצה 2 אם אינך משתמש בפינים 7–11 לייצוב.
  כיול 6 צירים מוטמע במקלט ויש להריץ אותו פעם אחת במקלט חדש, ושוב לאחר כל
  עדכון קושחה לגרסה v3.0.x (בעקבות איפוס להגדרות היצרן). תחת הכיול של כל
  קבוצה, שלב ה-"self-check" הישן הוחלף בכיול עצמאי של מפלס הכלי, מרכז הערוץ
  ונקודות הקצה של הערוץ, וכל ערוץ ניתן להפעלה/כיבוי בנפרד. ניתן לשמור
  הגדרות (לא נתוני כיול) למחשב ולשחזר אותן ממנו.
- **SxR** — מקלטים ותיקים יותר, כולל יחידות מדור קודם ו-Archer/Archer Pro,
  וכן מקלטים כמו ה-SR10 Pro שבהם (למרות השם "SRx") ה-Gain נמצא בערוץ 9 ולא
  בערוץ 13.

  ![ההתקן הנוכחי](../assets/system-devices-current.png)

!!! warning "לאחר עדכון לקושחת מקלט v3.0.x"
    בצע איפוס להגדרות היצרן (נמצא תחת Options של המקלט בהגדרות RF), לאחר מכן
    בצע קישור מחדש והגדרה מלאה מחדש — במיוחד של פונקציות ה-Stab וכיול 6
    הצירים. הדבר נדרש בשל תכונת שמירת נתוני ה-failsafe החדשה ב-v3.0.x; בדוק
    היטב את פונקציית ה-failsafe לאחר מכן.

FrSky North America מפרסמת מדריך מפורט להגדרת מקלטים מיוצבים, וקיים גם סרטון
הדרכה מפורט מאת Juan Sanchez Garcia, טייס צוות FrSky, המכסה את אותו החומר.

## הגדרה דרך מחבר S.Port של המשדר

ניתן להגדיר התקני S.Port ו-FBUS גם ישירות דרך מחבר ה-S.Port שבחלק העליון של
המשדר, בלי לעבור דרך מקלט מקושר.

1. חבר את ההתקן למחבר ה-S.Port של המשדר (המוליך הלבן/צהוב לכיוון הצד המחורץ).
2. עבור אל **System → Device config**, גלול אל ההתקן (למשל חיישן זרם FAS40
   ADV) ולחץ `ENT`.
3. בדף ההגדרות, קבע את **Module** ל-**S.Port connector**.
4. בצע את השינויים — ה-Physical ID וה-Application ID חייבים להיות ייחודיים
   כל אחד — לאחר מכן גלול למטה והקש על **Save to flash**.

הדבר תקף גם עבור התקני FBUS (ראה גם [מדריך הדרכה: הגדרת מערכת
FBUS](../how-to/fbus-setup.md)) וגם עבור התקני S.Port פשוטים כגון וריומטר.
