# Ethos Suite

Ethos Suite היא אפליקציית הלוויין ל‑Windows/Mac לניהול משדר המריץ Ethos, המחובר דרך USB.

!!! note "צילומי מסך בהמתנה"
    Ethos Suite היא אפליקציית PC נפרדת, ולא המשדר עצמו, ולכן פרק זה אינו משתמש בצילומי המסך שנלקחו מהסימולטור כמו בשאר המדריך — ראה [תהליך צילומי המסך](../contributing/screenshot-pipeline.md).

לאחר החיבור, Ethos Suite יכולה:

1. לקרוא את סוג המשדר, ה‑ID והגרסאות המותקנות — קושחה, bootloader, מודול RF פנימי, קבצי זיכרון flash וקבצי SD card/eMMC.
2. להעביר את המשדר בין מצב bootloader לבין הרצת Ethos, ובחזרה.
3. להשוות את הגרסאות המותקנות לגרסאות הנוכחיות ולעדכן אוטומטית — רק רכיבים מיושנים, הכול ללא תלות בגרסה, או רכיבים בנפרד.
4. לגבות דגמים לדיסק באמצעות **Model Manager**, או לשחזר גיבוי קודם (נדרש מכיוון שקבצי הדגמים אינם תואמים לאחור בין גרסאות קושחה).
5. להוריד כל קושחה מאתר ההורדות של FrSky דרך ה‑**Download center**, ולהשתמש במשדר כמתווך לצריבת מודול, חיישן, סרוו או מקלט באופן ישיר.
6. להמיר קבצי תמונה ושמע לפורמטים המקוריים של Ethos.
7. לספק **כלי פיתוח Lua** — תיעוד API, סקריפטים לדוגמה וטרמינל ניפוי באגים.
8. לצרוב את ה‑bootloader של המשדר במצב DFU (חיבור במצב כבוי), ללא תלות בשאלה אם הקושחה של המשדר עצמה עדיין פועלת.
9. לתקן את האחסון הפנימי במשדרי X18/S, TW Lite, XE ו‑X20 Pro/R/RS באמצעות ה‑**Repair Tool**, אם לא ניתן לקרוא את ה‑NAND או שההגדרות אינן נשמרות.
10. לנתק את כונני ה‑USB של המשדר בצורה נקייה.
11. להודיע בעת ההפעלה כאשר קיים עדכון ל‑Suite עצמה (מותקן בעת היציאה).

## מצבי חיבור

מעבר לכלים שלה, Suite פועלת בשלושה מצבי חיבור נפרדים למשדר:

- **משדר במצב Bootloader** — לשונית **Radio** בודקת ומעדכנת את הקושחה ואת קבצי ה‑flash/SD card/eMMC; **Model Manager** מגבה או משחזר את המשדר.
- **משדר במצב Ethos** — Suite משתמשת במשדר כמתווך (דרך הכלים **FRSK Flasher**/Download center) לצריבת המודול הפנימי, או כל חיישן/סרוו/מקלט מחובר, באופן ישיר.
- **משדר במצב DFU** — חיבור במצב כבוי, המשמש את ה‑**DFU Flasher** לצריבת ה‑bootloader עצמו, למשל כאשר קושחה פגומה מונעת מהמשדר להידלק כרגיל.

ראה [מיגרציה](migration.md) להעברת משדר קיים ל‑Ethos Suite בפעם הראשונה, ו‑[הפעלה](operation.md) לממשק ה‑Suite עצמו.
