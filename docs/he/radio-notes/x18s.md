# X18S

![בדיקת חומרה של X18S](../assets/system-hardware-check-x18s.png)

הבדלים מבסיס ה-X20S שעליו נכתב מדריך זה:

- **אחסון** — eMMC פנימי בנפח 8GB כברירת מחדל (ניתן להוסיף לצידו SD card
  חיצוני), בדומה ל-X20 Pro/R/RS — ראו [הגדרות מערכת →
  כללי → מיקום
  אחסון](../system-setup/general.md#storage-location-x18-and-x20-prorrs)
  ו[מנהל הקבצים](../system-setup/file-manager.md).
- **טרימים נוספים** — בדומה ל-X20 Pro/R/RS, מוסיף את מתגי הטרים **T5** ו-**T6**
  מעבר לארבעה הסטנדרטיים — ראו
  [טרימים](../model-setup/trims.md#trim-settings).
- **[בדיקת חומרה](../system-setup/hardware.md#hardware-check)** ו[בוחן
  ערכי ADC](../system-setup/hardware.md#adc-value-inspector)
  כוללים בבדיקותיהם גם את הטרימים T5/T6 בהתאם.
