# Documentazione Ethos Lua

Il riferimento completo delle API Lua di Ethos è incluso in **Ethos Suite**, nella
scheda **Lua Development Tools** (strumenti di sviluppo Lua): è il riferimento
autorevole per ogni chiamata `system.*`, `lcd.*` e per tutte le altre API disponibili
a uno script, ed è sempre allineato alla versione di Ethos con cui viene distribuito.

Consulta [Ethos Suite](../ethos-suite/index.md) per l'installazione e l'utilizzo
dell'applicazione per PC.
