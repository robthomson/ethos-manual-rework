# Alternative Lua display themes

È possibile installare temi alternativi per la visualizzazione utilizzando uno script Lua. Quattro esempi sono disponibili nella cartella \`lua/examples/theme\` del ramo 26.1 del repository Ethos-Feedback-Community su GitHub

| Dark (Ethos 1.6) | -- Colori di Ethos 1.6.6 |
| --- | --- |
| Dark (Copy) | -- Colori dal tema standard scuro (commentato) |
| Light (Copy) | -- Colori dal tema standard chiaro (commentato) |
| Dark Outline | -- Colori del tema scuro, ma con stile focus Outline (bordo di 2 px) |

Per installare questi temi, fare riferimento alla sezione “Posizione dei file di script di esempio Lua di ETHOS” riportata sopra, scaricare il file “theme/main.lua” e salvarlo nella cartella “theme” all'interno della cartella ‘scripts’ sulla scheda SD o sull'eMMC, oppure utilizzare uno strumento di download per scaricare la cartella “theme”. Al riavvio della radio, i temi alternativi saranno installati e risulteranno disponibili nell'elenco a discesa Sistema / Generale / Tema.  
  
Il file dei temi di esempio include copie dei temi standard chiaro e scuro che possono essere modificati in base alle proprie preferenze.



Once installed, two additional themes will appear in the System / General / Theme options list. The first is the ‘Dark (Ethos1.6)’ theme with the colors and shading from Ethos 1.6.



The second additional theme uses outlines for the focus instead of the standard inverted highlight.
