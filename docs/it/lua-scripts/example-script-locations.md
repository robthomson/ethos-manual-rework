# Posizione degli script di esempio

Gli script di esempio ufficiali sono pubblicati su
[github.com/FrSkyRC/ETHOS-Feedback-Community](https://github.com/FrSkyRC/ETHOS-Feedback-Community/tree/main/lua)
(in particolare `/lua/examples/task` e `/lua/examples/source`). La maggior parte
degli esempi sono widget Lua (configurati in [Configura
schermate](../displays/custom-widgets.md)); l'esempio **`servo`**
mostra in particolare uno **Strumento di sistema**, ossia uno script che compare dopo
**Info** nel menu SYS anziché come widget di visualizzazione.

## Scaricare uno script

1. Apri il link al repository indicato sopra in un browser e vai alla
   cartella desiderata, quindi al file `main.lua` che ti interessa.
2. Clicca sul file per visualizzarlo, quindi su **Raw**.
3. Clicca con il tasto destro sulla pagina → **Salva pagina con nome…**, salvandola come `main.lua`.
4. Per evitare conflitti con i file `main.lua` di altri script, spostalo in una
   cartella con un nome corrispondente: il nome della cartella di origine è una
   scelta ragionevole.

Per gli eventuali altri file necessari allo script (immagini, ecc.): clicca sul file, clicca su
**Download**, quindi clicca con il tasto destro e seleziona **Salva immagine con nome…** (o equivalente) per
salvarlo insieme allo script.

Gli script vengono installati nella cartella `scripts/` della SD card o eMMC: consulta [Gestore
file](../system-setup/file-manager.md#top-level-folders).

Consulta anche la discussione *FrSky ETHOS Lua Script Programming* su rcgroups per
script della community e approfondimenti che vanno oltre gli esempi ufficiali.
