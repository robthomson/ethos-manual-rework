# Posizione degli script di esempio

Gli script di esempio ufficiali sono pubblicati su
[github.com/FrSkyRC/ETHOS-Feedback-Community](https://github.com/FrSkyRC/ETHOS-Feedback-Community/tree/main/lua)
(in particolare `/lua/examples/task` e `/lua/examples/source`). La maggior parte
degli esempi sono widget Lua (configurati in [Configura
schermate](../displays/custom-widgets.md)); l'esempio **`servo`**
dimostra in particolare uno **Strumento di sistema** — uno script che compare dopo
**Info** nel menu System anziché come widget di visualizzazione.

## Scaricare uno script

1. Apri in un browser il link al repository indicato sopra e naviga fino alla
   cartella, quindi al file `main.lua`, desiderato.
2. Fai clic sul file per visualizzarlo, quindi su **Raw**.
3. Fai clic con il tasto destro sulla pagina → **Salva pagina con nome…**, salvandola come `main.lua`.
4. Per evitare conflitti con i file `main.lua` di altri script, spostalo in una
   cartella con un nome corrispondente — il nome della cartella di origine è una
   scelta sensata.

Per gli eventuali altri file necessari a uno script (immagini, ecc.): fai clic sul file, fai clic su
**Download**, quindi fai clic con il tasto destro e scegli **Salva immagine con nome…** (o equivalente) per
salvarlo insieme allo script.

Gli script vengono installati nella cartella `scripts/` della SD card/eMMC — vedi [Gestore
file](../system-setup/file-manager.md#top-level-folders).

Vedi anche la discussione *FrSky ETHOS Lua Script Programming* su rcgroups per
script della community e approfondimenti oltre agli esempi ufficiali.
