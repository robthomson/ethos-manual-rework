# Riorganizzazione del menu della Radio

![](../assets/Pictures/1000000100000320000001E081112C2C.png)

Le voci del menu del modello possono essere riorganizzate in base alle proprie preferenze. Toccando e tenendo premuto a lungo si attiverà l'opzione. Le icone del menu del modello verranno visualizzate con delle linee tratteggiate per indicare che l'opzione di riorganizzazione è attiva.

Nota: Questa funzionalità non è disponibile su Rdio senza touchscreen.

![](../assets/Pictures/100000010000063A000003C00680B851.png)

Ora è possibile trascinare le voci del menu di esempio per disporle come preferisci. Tocca fuori dalle icone o premi RTN per terminare la modifica.
