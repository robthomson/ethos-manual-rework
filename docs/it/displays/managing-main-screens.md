# Aggiungere widget personalizzati

I widget personalizzati sono in genere script lua che si presentano sotto forma di un singolo file "main.lua", che viene comunemente conservato in una sottocartella con un nome che ne suggerisce la funzionalità.

Questa sottocartella deve essere copiata nella cartella "scripts" della scheda SD o eMMC. Il widget verrà registrato automaticamente all'avvio. Le schermate di configurazione possono essere utilizzate per configurare il widget come qualsiasi altro.
