# 示例脚本位置

官方示例脚本发布于
[github.com/FrSkyRC/ETHOS-Feedback-Community](https://github.com/FrSkyRC/ETHOS-Feedback-Community/tree/main/lua)
（尤其是 `/lua/examples/task` 与 `/lua/examples/source`）。大多数
示例为 Lua 小组件（在[配置显示屏](../displays/custom-widgets.md)中设置）；其中 **`servo`** 示例
专门演示了 **系统工具** —— 该类脚本出现在系统菜单中
**Info** 之后，而不是作为显示小组件。

## 下载脚本

1. 在浏览器中打开上方的仓库链接，浏览至所需的文件夹，再进入所需的 `main.lua` 文件。
2. 点击该文件以查看内容，然后点击 **Raw**。
3. 在页面上右键 → **Save Page as…**（另存页面为…），保存为 `main.lua`。
4. 为避免与其他脚本的 `main.lua` 冲突，请将其移入一个名称相符的文件夹中 —— 使用源文件夹自身的名称是一个合理的选择。

对于脚本所需的其他文件（图片等）：点击该文件，点击
**Download**，然后右键并选择 **Save Image as…**（图片另存为…，或等效选项），将其与脚本保存在一起。

脚本安装在 SD card/eMMC 的 `scripts/` 目录下 —— 参见[文件管理器](../system-setup/file-manager.md#top-level-folders)。

除官方示例外，也可参阅 rcgroups 上的 *FrSky ETHOS Lua Script Programming* 主题帖，获取社区脚本与相关讨论。
