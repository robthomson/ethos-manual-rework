# 紧急模式

紧急模式是 Ethos 对意外底层故障（例如看门狗复位）的应对措施。看门狗是一个由系统各部分持续重启的计时器；如果某些原因导致它无法被重启，它就会超时并强制硬件复位。随后紧急模式会以最快速度重启遥控器，跳过所有常规启动检查，以最小的延迟将模型的控制权交还给操作者。在此模式下完全不会访问 SD card/eMMC。

此时仅提供维持控制模型所必需的基本功能——所有高级功能均不可用。屏幕除显示 **EMERGENCY MODE** 字样外一片空白，同时每 3 秒重复发出 300ms 的蜂鸣声；语音提示、Lua 脚本、日志记录和遥测全部停止。如果在飞行中发生这种情况，请尽快降落。

最常见的触发原因是 SD card 故障。

## 测试紧急模式

可以添加一个 **系统工具** 来故意触发紧急模式以进行测试，这样就不必在飞行中第一次遇到它。点击 Emergency Test 图标会提示确认，随后遥控器将进入紧急模式，其表现与真实故障时完全一致。
