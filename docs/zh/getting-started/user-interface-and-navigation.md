# 用户界面与操作导航

Ethos 可以完全通过右侧的**旋转编码器**（旋转移动高亮项，按下即 `ENT`）以及用于退出菜单的 `RTN` 键来操作——在配备触摸屏的机型上，触摸屏只是这些相同操作的快捷方式，而不是另一套独立的操作方式。`MDL`、`DISP` 和 `SYS` 分别直接跳转到模型设置、配置显示屏和系统设置（与底部栏的三个图块相同）；在任何界面下长按 `RTN` 都会直接返回主页。

## 复位菜单

![上下文菜单](../assets/resetmenu.png)

在主页上长按 `ENT` 会打开复位菜单：

- **复位飞行** —— 复位遥测数据、计时器和功能开关，并重新执行飞行前[检查清单](../model-setup/checklist.md)。
- **复位遥测** —— 仅复位遥测数据。
- **复位计时器** —— 仅复位计时器。
- **锁定触摸屏** —— 也可以在主页上同时按住 `ENT` + `PAGE` 一秒钟来实现，或作为[特殊功能](../model-setup/special-functions.md)的触发动作。

## 编辑控件

**添加功能元素** —— 计时器、逻辑开关、特殊功能、曲线或变量，通过点击相应菜单中列标题旁的 **+** 来创建。在非触摸屏遥控器上，高亮某个已有元素，按 `ENT`，然后从菜单中选择 **Add**（添加）——触摸屏遥控器上同样提供该选项。

### 虚拟键盘

![文本键盘](../assets/keyboard-text-azerty.png)

触摸任意文本框（或在其上按 `ENT`）即可打开屏幕键盘。退格键删除光标左侧的字符；`PAGE` 删除右侧的字符，当光标到达文本末尾后，会继续从左侧删除。触摸文本框本身可将光标移动到该位置——或者使用 `SYS`/`DISP` 在不触摸的情况下左右移动光标。**?123**/**abc** 键用于切换数字键盘（其中也包含特殊字符）：

![数字键盘](../assets/keyboard-text-numbers.png)

在**非触摸屏遥控器**上，在文本框上按 `ENT` 会直接进入编辑模式：旋转编码器可依次浏览小写字母、大写字母、数字，然后是特殊字符，按 `ENT` 插入所选字符。`MDL` 切换光标右侧紧邻字符的大小写（此后输入的每个字符都保持该大小写，直到再次切换）。`PAGE` 删除光标右侧的字符；`SYS`/`DISP` 左右移动光标。

## 数值控件

![数值输入](../assets/keyboard-numbers.png)

触摸数值字段会在屏幕底部打开一个控制条：**`<`**/**`>`** 改变步进大小（在各数量级之间循环——例如 0.01/0.1/1.0/10.0），**`-`**/**`+`**（或旋转编码器）按该步进调整数值，**More**（更多）则打开进一步的选项：

![数值输入选项](../assets/keyboard-numbers-options.png)

- 跳转到该字段的默认值
- 设为最小值 / 设为最大值
- 用**滑块**替代步进器

![滑块输入](../assets/keyboard-numbers-slider.png)

滑块（同样可用旋转编码器调节）在进行粗调时更快；**Disable slider**（禁用滑块）可恢复为步进器。遥测范围数值的编辑方式相同：

![滑块已禁用](../assets/keyboard-numbers-options-disable-slider.png)

## 选项功能 {: #the-options-feature }

几乎在任何需要输入数值或[信号源](#choosing-a-source)的位置，长按 `ENT` 都会打开**选项**对话框——字段左上角出现的小菜单（“汉堡”）图标即表示该功能可用。

### 数值选项

![信号源选项](../assets/source-with-options.png)

数值选项对话框会显示正在编辑的参数名称，并提供在固定最小值/最大值与由**信号源**驱动（例如用电位器在飞行中调整该数值）之间的选择。如果该字段已经使用了信号源，则同样的长按操作会改为提供将该信号源的当前值转换为固定数值的选项：

![将信号源转换为数值](../assets/source-convert-to-value.png)

### 选择信号源 {: #choosing-a-source }

选择 **Choose a source**（选择信号源）会打开一个两栏选择器——先选**类别**（模拟量、开关、逻辑开关、微调、通道、陀螺仪轴、教练通道、计时器、遥测传感器，或少量特殊值），再选择其中的具体成员：

![信号源菜单](../assets/source-menu.png)

信号源设定完成后，同样的长按操作会打开针对该信号源类型的专属选项：

**所有信号源** ——

- **Invert**（反相）—— 对信号源取反（例如在开关*不*处于上位时有效，而不是处于上位时有效）。
- **Edge**（边沿）—— 在状态跳变时触发一次（false→true 或 true→false），而不是在整个状态期间持续有效；该信号源前会显示 `†` 前缀。开关类信号源普遍支持，[黏性逻辑开关](../model-setup/logical-switches.md)的触发条件也专门支持。

**摇杆信号源** —— 校准/子微调类选项：

![摇杆信号源选项](../assets/source-stick-options.png)

**开关信号源** ——

![两位开关选项](../assets/source-2pos-options.png)
![开关选项](../assets/switch-options.png)

- **Negative**（取反）—— 反转开关动作。
- **HalfRange**（半量程）—— 对于两位开关或逻辑开关，将其输出范围从 ±100% 改为 0–100%。

**微调信号源** ——

![微调信号源选项](../assets/source-trim-options.png)

- **Negative**（取反）—— 反转微调动作（在自由混控的 Actions 中很有用）。
- **Full range**（全量程）—— 微调默认为 ±25%；作为信号源时可扩展到 ±100%。
- **Ignore trainer input**（忽略教练输入）—— 在[逻辑开关](../model-setup/logical-switches.md)中，排除教练输入引起的动作触发该开关。典型用途：检测*主控*教练自己的摇杆动作（例如学员操作失误时立即介入接管），而不会因学员的摇杆输入而误触发。

**变量信号源** ——

![变量信号源选项](../assets/source-var-options.png)

- **Negative**（取反）—— 在本次使用中对变量的数值取反。
- **Ignore range**（忽略范围）—— 某些字段具有非对称范围（例如输出的 Min/Max，分别为 −150–0% 和 0–150%）。除非作为该字段信号源的[变量](../model-setup/variables.md)具有完全相同的范围，否则应启用此项以跳过 Ethos 的自动范围转换，避免出现意外数值。

**遥测传感器信号源** —— 将信号源取其实时最小值或最大值，而非瞬时读数（部分传感器还会在此基础上提供更多针对该传感器的专属选项）：

![传感器最小/最大值选项](../assets/source-sensor-options.png)
![已选择传感器最大值](../assets/source-sensor-maxi.png)
