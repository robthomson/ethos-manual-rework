# 主视图

## 主屏幕

![主屏幕](../assets/mainview.png)

主屏幕即未打开任何菜单时所看到的界面——由最多 **8** 个由用户自行配置的显示屏叠放而成（参见
[显示屏](../displays/index.md)），可通过 `PAGE` 键或触摸滑动在各屏幕间翻页切换。新建的模型初始仅有一个屏幕，其中显示模型图片、三个计时器小组件以及微调/电位器指示条；此后屏幕上的所有内容均可由用户自行配置。

各屏幕通常共用下文所述的顶栏与底栏，但也可将某个屏幕设置为全屏模式，从而隐藏这两个栏。

## 顶栏

顶栏左侧显示模型名称（若已配置飞行模式，还会显示当前生效的飞行模式），右侧为一排状态图标：

- 数据记录进行中
- 教练状态（主控或从控，视具体情况而定）
- RSSI —— 2.4GHz 链路
- RSSI —— 900MHz 链路（若安装了双频段/远距离模块）
- 扬声器音量
- 遥控器电池状态

触摸扬声器或电池图标可直接跳转至对应的
[常规](../system-setup/general.md)（音频）或
[电池](../system-setup/battery.md)设置面板。

### 错误警告

每当 Ethos 检测到错误时，顶栏会出现一个红色三角形——常见原因包括 Lua 脚本错误、RAM 备份错误，或正在运行 nightly/不稳定版固件。该警告的详细信息始终可在 **System → Info** 中查看，与遥控器运行时间和[错误日志](../system-setup/information.md)位于同一页面。

## 底栏

![底栏](../assets/bottombar.png)

底部有四个标签页，对应各顶级分区——**主页**、**模型设置**、**配置显示屏**、**系统设置**——右侧为系统时钟（触摸即可直接跳转至[日期与时间](../system-setup/date-and-time.md)）。

## 小组件区域

每个屏幕的中间区域由**小组件**填充：模型图片、计时器、遥测数据读数、微调/电位器条等等，其位置与配置均由用户自行决定。有关如何添加、移动和配置小组件，请参见[显示屏](../displays/index.md)；如需在默认的单个屏幕之外添加更多屏幕，请参见[附加显示屏](../displays/additional-displays.md)。
