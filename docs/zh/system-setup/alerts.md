# 警报

![警报](../assets/system-alerts.png)

四项全局遥控器警告，每项均可独立开关 — 与你自行创建的按模型[特殊功能](../model-setup/special-functions.md)和[逻辑开关](../model-setup/logical-switches.md)相互独立。

- **静音模式** — 当此项检查开启且[通用设置 → 音频模式](general.md)设为静音时，开机时会发出语音提示，用于提醒遥控器已处于静音状态。
- **主电池电压** — 当遥控器主电池电压低于[电池](battery.md)中设定的**低电压**阈值时，播报"Radio battery is low"（遥控器电池电量低）。
- **RTC 电压** — 当 RTC 纽扣电池电压低于 2.5V（默认阈值）时，播报"RTC battery is low"（RTC 电池电量低）。数据记录依赖实时时钟，时间无效会使日志难以阅读，尤其是难以区分不同的飞行场次。在等待更换电池期间可以临时关闭此提示，但不应长期关闭。
- **传感器冲突警告** — 检测遥测传感器 ID 冲突。只有在使用不符合 S.Port 规范的传感器时，才有必要关闭此项。
- **闲置提醒** — 当遥控器闲置时间超过设定值（默认 10 分钟）后，播报"Prolonged inactivity"（长时间未操作）语音提示，并伴随振动提醒（以防音量已调低）。
