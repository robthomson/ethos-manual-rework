# 电池

![遥控器电池设置](../assets/system-battery.png)

用于校准遥控器内置电池的读数并设置报警阈值——这与模型的动力电池设置无关（参见[操作指南：低电压报警](../how-to/low-battery-warning.md)）。

- **主电压** — 显示当前读数，同时兼作校准调整项：输入用万用表实测得到的实际电压。默认值为 8.4V（一组充满电的 2S 锂离子电池）。
- **低电压** — 报警阈值，默认 7.2V（设为 7.4V 可留出更多余量）。当[主电压提醒](alerts.md)开启时，电压低于该值将触发警告对话框，并每分钟播报一次“Radio battery is low”语音提醒，无论对话框是否处于打开状态。

  !!! warning
      一旦该提醒响起，应尽快降落并为遥控器电池充电——它会每分钟重复一次，无法忽略。电压降至 6.0V 时，遥控器将无条件关机，以保护 2×3.0V 的锂离子电芯。

- **显示电压范围** — 右上角图形化电池显示的最小/最大值：MIN 为第一格电量条变暗的电压，MAX 为第四格点亮的电压。内置锂离子电池的默认值为 6.4–8.4V；许多飞手会提高下限值，以便更早获得低电压警告，避免过放。请根据实际安装的电池类型设置这两个值。
- **RTC 电压** — 实时时钟纽扣电池的电压。全新时为 3.0V；低于 2.7V 时应予更换以保持时钟准确，低于 2.5V 时会出现[RTC 电压提醒](alerts.md)。
