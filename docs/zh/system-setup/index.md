# 系统设置

系统设置用于配置遥控器中所有模型共用的部分——通过底部栏的 **齿轮** 标签页（或 `SYS` 键）进入。仅适用于单个模型的设置则位于 [模型设置](../model-setup/index.md)（**飞机** 标签页 / `MDL` 键）中——尤其需要注意的是，某个模型使用哪个 RF 模块（内置或外置）属于每个模型各自的设置，位于 [RF System](../model-setup/rf-system.md) 中，而不在此处。

触摸磁贴即可打开，或用旋转选择器移动高亮位置并按 `ENT`。磁贴还有第二页——向左滑动、将高亮移到该页，或按 `PAGE` 键切换。

- [File Manager](file-manager.md) —— 文件与文件夹管理，以及为内置 RF 模块、S.Port 设备、OTA 和外置模块刷写固件。
- [Alerts](alerts.md) —— 静音模式、遥控器电池/RTC 电池、传感器冲突以及闲置警告。
- [Date & Time](date-and-time.md) —— 系统时钟及其显示方式。
- [General](general.md) —— 语言、显示、音频、升降速率提示音、振动、顶部工具栏、开机时的模型以及 USB 模式预选。
- [Battery](battery.md) —— 遥控器电池管理。
- [Hardware](hardware.md) —— 检查与校准物理控制部件、开关类型定义以及主页按键映射。
- [Controls](controls.md) —— 摇杆模式与默认通道顺序（菜单中显示为 "Sticks"）。
- [Devices](devices.md) —— 传感器、接收机、燃油动力套件、舵机以及图传发射机（菜单中显示为 "Device config"）。
- [Information](information.md) —— 固件版本、摇杆类型、RF 模块信息、运行时间以及错误日志。
