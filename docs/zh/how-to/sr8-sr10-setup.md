# SR8/SR10 模型设置与通道重排

FrSky 的 SRx 增稳接收机要求特定的通道顺序。有两种情形：从零开始为其新建模型，或将现有模型改为匹配该顺序。

!!! note "截图待补充"
    本页尚无模拟器截图 —— 参见 [截图流程](../contributing/screenshot-pipeline.md)。

## 新建模型

[Model Select](../model-setup/model-select.md) 向导默认会将功能相同的舵面归组（例如 2 个副翼 → `AAETR`），但 SRx 接收机需要将前四个通道固定为 **AETRA**。

1. 在 [控制](../system-setup/controls.md) 中，确认 **通道顺序** 为 `AETR`。
2. 启用 **[前四通道固定](../system-setup/controls.md#first-four-channels-fixed)** —— 此选项会阻止向导对前四个通道进行归组，无论机体上每种舵面有多少个，都严格保持 `AETRA…` 的顺序。
3. 照常运行模型创建向导 —— 前 5 个通道即为 `AETRA`。

!!! note "Archer 接收机自检"
    Archer 接收机的自检现已通过 [设备配置 → SxR](../system-setup/devices.md) 进行（固件 v2.1.10 及以上），而不再使用专门的自检流程。油门通道必须处于 −100%，否则自检不会启动。

## 重排现有模型

将现有模型（例如当前为 `AAETRFF`）转换为增稳接收机的顺序（`AETRAE`，随后通道 9 为增益，10/11 为飞行模式，较早期 SxR 机型的通道 12 为自检），需要在 [输出](../model-setup/outputs.md#swap-channels) 中执行一系列通道交换。

起始状态：

| 通道 | 功能 |
|---|---|
| 1 | 副翼1（右） |
| 2 | 副翼2（左） |
| 3 | 升降舵 |
| 4 | 油门 |
| 5 | 方向舵 |
| 6 | 襟翼1（右） |
| 7 | 襟翼2（左） |
| 8 | 收放起落架 |

目标顺序：`AETRAE` —— 通道1 副翼1，通道2 升降舵，通道3 油门，通道4 方向舵，通道5 副翼2，通道6 升降舵2/AUX2（随后通道 9–12 为增益/飞行模式/自检）。

1. **首先将副翼2 挪开**：在输出中选择 CH2（副翼2），再次点按，选择 **交换通道**，将其与一个未使用的通道（例如 CH9）交换。交换立即生效 —— 所有引用这两个通道的混控都会自动更新。
2. **将 CH3（升降舵）交换到 CH2。**
3. **将 CH4（油门）交换到 CH3。**
4. **将 CH5（方向舵）交换到 CH4。**
5. **将 CH9（第 1 步中暂存的副翼2）交换到 CH5。**

结果：

| 通道 | 功能 |
|---|---|
| 1 | 副翼1（右） |
| 2 | 升降舵 |
| 3 | 油门 |
| 4 | 方向舵 |
| 5 | 副翼2（左） |
| 6 | 襟翼1（右） |
| 7 | 襟翼2（左） |
| 8 | 收放起落架 |

—— 此时即为 FrSky 增稳接收机所要求的顺序。
