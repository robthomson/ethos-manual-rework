# 测试冗余接收机配置

冗余配置只有在飞行前经过实际测试才有意义 —— 本文假定[冗余接收机](../model-setup/rf-system.md#redundant-receivers)已经配置完成。

!!! note "截图待补充"
    本页面尚无模拟器截图 —— 参见[截图流程](../contributing/screenshot-pipeline.md)。

## A. 实地测试

主接收机使用 2.4GHz，冗余接收机使用 900MHz，启动[距离检测](../model-setup/rf-system.md#range-check)并逐渐远离模型，直至 2.4GHz 信号丢失（超过 RSSI 严重告警之后）。此时 900MHz 冗余接收机应接管控制。

## B. 台面测试

1. **确认配置正常** —— 两个接收机均已对频，两个绿色 LED 均点亮，各舵面响应正常。
2. **将主接收机对频到另一个 Model ID** —— 新建一个临时测试模型（例如 “TestRx”），为其设置不同的 Model ID，并将*主*接收机对频到该模型。随后切回被测模型：主接收机的 LED 此时应为**红色**（已对频到别处），而冗余接收机的 LED 保持**绿色** —— 并且各舵面仍应正常动作，这证明仅靠冗余接收机即可维持模型可飞行。
3. **将主接收机重新对频**回其正常的 Model ID。在认为测试完成之前，确认两个 LED 重新变为绿色且各舵面动作正常。
