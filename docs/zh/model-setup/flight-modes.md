# 飞行模式

![飞行模式](../assets/model-fm.png)

飞行模式（飞行阶段）允许通过一个开关，在同一模型上切换不同的行为特性——滑翔机可能使用抛飞/巡航/竞速/热气流，动力固定翼使用普通/起飞/降落，直升机使用普通（升速、起飞/降落）/ Idle Up 1（特技）/ Idle Up 2（3D）。它们可以将大部分手动切换与重新调整微调的负担从飞行员身上卸下：每个飞行模式可以拥有各自独立的微调，并且可以同时控制 [变量](variables.md) 与 [混控设置](mixes.md) 的启用——两者结合，足以应对真正复杂的需求。有关飞行模式在实际模型上的应用，请参阅 [固定翼基础示例](../tutorials/basic-fixed-wing.md)。

默认情况下未定义任何飞行模式。点击默认飞行模式并选择 **编辑** 可为其重命名，或选择 **添加** 新建一个飞行模式——最多可创建 20 个。

## 名称

一个具有描述性的名称——巡航、竞速、热气流、起飞、降落，只要贴合用途即可。

## 激活条件

![飞行模式设置界面](../assets/model-fm-form.png)

新建的飞行模式初始为未激活状态（`---`）。设定之后，它可以由开关或按键位置、功能开关、逻辑开关、系统事件（油门切断/油门保持）或微调位置来驱动。

**默认** 飞行模式完全没有激活条件——只要没有其他任何飞行模式的条件成立，它就处于激活状态。同一时刻只会有一个飞行模式处于激活状态：即（按优先级顺序）第一个当前条件成立的飞行模式。处于激活状态的模式以粗体显示。

!!! warning "向已有模型添加飞行模式"
    新添加的飞行模式，默认在所有已经依赖飞行模式的混控中都处于激活状态——请检查每一个此类混控是否仍然工作正常，尤其是将某个通道锁定到特定飞行模式的 **Lock** 混控。

## 渐入、渐出

用于在飞行模式之间平滑过渡的时间（例如各方向 1 秒）——该设置仅对本身依赖飞行模式的混控有效。

## 飞行模式管理

![移动飞行模式](../assets/model-fm-move.png)
![选择要移动的位置](../assets/model-fm-move-select.png)
![模式 0-3](../assets/model-fm-0to3.png)

点击某个飞行模式可进行 **编辑**、**添加**、**克隆** 或 **删除**。**克隆** 出的飞行模式会在所有使用飞行模式的混控中继承其源模式的设置——行为相同，激活/未激活状态也相同——因此克隆出的飞行模式默认被添加为最后一个飞行模式，以避免干扰已有的飞行模式。**移动** 用于改变飞行模式的优先级：优先级按升序排列，并且（如上所述）条件成立的第一个飞行模式即为当前激活的飞行模式。
