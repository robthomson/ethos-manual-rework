# 模型设置

本节中的所有内容均**按模型**存储——切换模型即切换全部这些设置。模型的实际编程就在这里完成，从选择机型模板开始，直至其混控、输出与安全开关。可通过底部栏的**飞机**选项卡（或 `MDL` 键）进入——与[系统设置](../system-setup/index.md)不同，后者涵盖对所有模型通用的内容。

- [模型选择](model-select.md) —— 创建、选择与整理模型。
- [模型编辑](model-edit.md) —— 模型自身的名称、类型与图标。
- [飞行模式](flight-modes.md)
- [混控设置](mixes.md) —— 模型编程的核心。
- [输出](outputs.md) —— 舵机/电机行程端点、微调偏置与反向。
- [计时器](timers.md)
- [微调](trims.md)
- [RF 系统](rf-system.md) —— 接收机对频与射频模块设置。
- [曲线](curves.md)
- [逻辑开关](logical-switches.md)
- [特殊功能](special-functions.md)
- [变量](variables.md)
- [教练功能](trainer.md)
- [遥测](telemetry.md) —— 传感器发现与计算传感器。
- [检查清单](checklist.md)
- [Lua 脚本](lua-scripts.md) —— 按模型配置的 Lua 脚本与功能。

有关模型编程从头到尾的完整实例，请参见[教程](../tutorials/index.md)；有关针对具体任务的操作步骤，请参见[操作指南](../how-to/index.md)。
