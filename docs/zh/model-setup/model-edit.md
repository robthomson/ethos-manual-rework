# 模型编辑

![编辑模型](../assets/model-editmodel.png)

用于编辑向导初次设置的模型级参数——主要是模型标识信息，同时也包含少量的单模型覆盖设置和实用功能。

## 名称、图片

重命名模型或更换模型图片；浏览图片时会显示预览缩略图。

## 模型类型

![模型类型](../assets/model-edit-modeltype.png)

!!! warning
    更改模型类型会重置**所有**混控设置。

## 通道分配

更改尾翼类型（或直升机的十字盘类型）同样会重置所有混控设置。其他通道可以更改其分配的数量，或取消分配。

## 模拟量滤波

![模拟量滤波](../assets/model-edit-analog-filter.png)

[系统设置 → 硬件](../system-setup/hardware.md)中提供了一个全局的模数转换滤波器，可减小摇杆中位附近的抖动；此处的单模型设置仅针对当前模型覆盖该全局设置。

![模拟量滤波选项](../assets/model-edit-analog-filter-select.png)

## 功能开关 {: #function-switches }

![功能开关](../assets/model-edit-fn-switches.png)

六个功能开关可在任何出现**激活条件**参数的位置使用，但与普通开关不同，它们不能作为通用信号源使用。可将其配置为以下模式之一：

- **6 位带 OFF** —— 按下某个功能开关将其锁定为开启状态；再次按下*同一个*开关则关闭全部六个开关。
- **6 位** —— 按下某个功能开关将其锁定为开启状态，直到按下*另一个*开关接替它。
- **2 × 3 位** —— 将六个开关分为两组，每组三个，每组内只有一个开关处于激活状态。
- **6 × 2 位** —— 六个相互独立的锁定式开关（开/关）。
- **瞬时** —— 六个相互独立的开关，仅在按住时为开启状态。
- **保持状态** —— 若启用，功能开关在断电或重新加载模型后仍保持其状态，而不会被重置。

![功能开关选项](../assets/model-edit-fn-switches-select.png)

## SPort 接口

发射机 S.Port 接口的 5V 引脚可按模型分别设置——例如在教练机设置中为外部接收机供电时非常有用。

## 模型运行时间

![模型运行时间](../assets/model-edit-model-runtime.png)

统计该模型累计飞行/运行的总时间。

## 重置所有混控

![重置所有混控](../assets/model-edit-model-reset_all_mixes.png)

将该模型的每一条混控设置恢复为默认状态。
