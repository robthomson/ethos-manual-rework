# Ethos 使用手册

**Ethos** 是运行在 FrSky Ethos 系列遥控器（X20S、X20 Pro、X20 Pro AW、X18S 等）上的操作系统。本手册涵盖从零开始建立模型、配置遥控器的系统级设置、构建自定义遥测显示界面，以及在此之上的 Lua 脚本运行环境。

## 从何处开始

- 初次接触 Ethos？请从[快速入门](getting-started/index.md)开始 —— 在改动任何设置之前，先了解主界面布局和导航方式。
- 正在设置一台新遥控器？请查看[系统设置](system-setup/index.md)，了解只需设置一次的、面向整机的选项（硬件校准、提示告警、电池）。
- 正在编程一个模型？[模型设置](model-setup/index.md)涵盖混控、输出、飞行模式以及其他所有按模型保存的内容，而[教程](tutorials/index.md)则完整演示如何搭建固定翼、飞翼和直升机模型。
- 想要构建遥测屏幕？请查看[显示屏](displays/index.md)。
- 想快速解决某个具体任务？请查看[操作指南](how-to/index.md)。
- 编写或安装 Lua 脚本／小组件？请查看[Lua 脚本](lua-scripts/index.md)。

## 适用机型

本手册主要以 **X20S** 为基准编写，在界面存在差异之处，会在[遥控器说明](radio-notes/index.md)中指出各机型（X20 Pro、X20 Pro AW、X18S）的特定区别。
