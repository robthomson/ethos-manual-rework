# 工具栏

Ethos 的每个界面——无论是主页还是菜单——上下都有两条常驻的工具栏。

## 顶部栏

![顶部栏](../assets/topbar.png)

从左至右依次显示：当前模型的名称/图标、RF 链路状态、RSSI、遥控器与接收机的电池电压，以及时间——可在
[系统设置 — 通用](../system-setup/general.md) 中进行配置。

## 底部栏

![底部栏](../assets/bottombar.png)

以实时条形图显示各输出通道的数值——与
[通道显示小组件](../displays/index.md#widget-types) 所显示的信息相同，无论当前处于哪个显示屏界面都始终可见。
