# X18S

![X18S 硬件检查](../assets/system-hardware-check-x18s.png)

与本手册所依据的 X20S 基准型号的差异：

- **存储** — 默认配备 8GB 内部 eMMC（可另外加装外置 SD card），与 X20 Pro/R/RS 相同 — 参见[系统设置 →
  通用 → 存储
  位置](../system-setup/general.md#storage-location-x18-and-x20-prorrs)
  和[文件管理器](../system-setup/file-manager.md)。
- **额外微调** — 与 X20 Pro/R/RS 一样，在标准的四个微调之外增加了微调开关 **T5** 和
  **T6** — 参见
  [微调](../model-setup/trims.md#trim-settings)。
- **[硬件检查](../system-setup/hardware.md#hardware-check)** 和
  [ADC 数值查看器](../system-setup/hardware.md#adc-value-inspector)
  的检查项中相应包含了 T5/T6 微调。
