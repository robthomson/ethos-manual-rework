# Radio Notes

This manual is written primarily against the **X20S**. This section covers
where other Ethos radios' UI or hardware differs.

- [X18S](x18s.md)
- [X20 Pro / X20 Pro AW](x20-pro-and-aw.md)

As of Ethos 26.1, the **XE/XES/XE RS**, **X14/X14RS**, and **TWIN XLite**
radio families are also supported. The source manual's coverage of them
is limited to hardware layout diagrams with no accompanying prose to
draw on, so they don't have their own page here yet — the one confirmed
functional difference so far is the XE series' physical switch labeling
(**S1**–**S14** rather than **SA**–**SN**), covered under [Hardware →
Switches settings](../system-setup/hardware.md#switches-settings).
