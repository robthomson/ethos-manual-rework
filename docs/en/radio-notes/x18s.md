# X18S

![X18S hardware check](../assets/system-hardware-check-x18s.png)

Differences from the X20S baseline this manual is written against:

- **Storage** — an internal 8GB eMMC by default (an external SD card can
  be added alongside it), same as the X20 Pro/R/RS — see [System Setup →
  General → Storage
  location](../system-setup/general.md#storage-location-x18-and-x20-prorrs)
  and [File Manager](../system-setup/file-manager.md).
- **Extra trims** — like the X20 Pro/R/RS, adds trim switches **T5** and
  **T6** beyond the standard four — see
  [Trims](../model-setup/trims.md#trim-settings).
- **[Hardware check](../system-setup/hardware.md#hardware-check)** and
  the [ADC value inspector](../system-setup/hardware.md#adc-value-inspector)
  include the T5/T6 trims in their checks accordingly.
