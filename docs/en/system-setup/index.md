# System Setup

System Setup covers the radio-wide settings that apply across every model —
things you generally configure once, right after unboxing or resetting the
radio, rather than per-model.

- [File Manager](file-manager.md) — browsing the SD card, transferring
  firmware, sounds, and bitmaps.
- [Alerts](alerts.md) — audible/haptic warnings for radio-level events.
- [Date & Time](date-and-time.md)
- [General](general.md) — brightness, sleep, audio, haptics, USB behavior.
- [Battery](battery.md) — the radio's own internal battery configuration.
- [Hardware](hardware.md) — stick, pot, switch, and gyro calibration.
- [Controls](controls.md) — stick mode and receiver channel order.
- [Devices](devices.md) — internal/external RF module selection.
- [Information](information.md) — radio runtime, errors, factory reset.
