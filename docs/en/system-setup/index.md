# System Setup

System Setup configures the parts of the radio that are common to every
model — reached via the **Gear** tab along the bottom bar (or the `SYS`
key). Everything specific to one model instead lives under [Model
Setup](../model-setup/index.md) (the **Airplane** tab / `MDL` key) —
notably, which RF module a model uses (internal or external) is a
per-model setting under [RF System](../model-setup/rf-system.md), not
here.

Touch a tile to open it, or move the highlight with the rotary selector
and press `ENT`. There's a second page of tiles — swipe left, move the
highlight onto it, or press `PAGE` to switch.

- [File Manager](file-manager.md) — files and folders, and flashing
  firmware to the internal RF module, S.Port devices, OTA, and external
  modules.
- [Alerts](alerts.md) — silent mode, radio/RTC battery, sensor conflict,
  and inactivity warnings.
- [Date & Time](date-and-time.md) — the system clock and its display.
- [General](general.md) — language, display, audio, vario, haptics, top
  toolbar, model-at-power-on, and USB mode preselection.
- [Battery](battery.md) — radio battery management.
- [Hardware](hardware.md) — checking and calibrating the physical
  controls, switch type definitions, and the home key map.
- [Controls](controls.md) — stick mode and default channel order (called
  "Sticks" in the menu).
- [Devices](devices.md) — sensors, receivers, the gas suite, servos, and
  video transmitters (called "Device config" in the menu).
- [Information](information.md) — firmware version, gimbal types, RF
  module info, runtime, and error logs.
