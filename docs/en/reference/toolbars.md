# Toolbars

Two persistent bars frame every screen in Ethos, home screen or menu alike.

## Top bar

![Top bar](../assets/topbar.png)

Shows, left to right: the current model's name/icon, RF link status, RSSI,
radio and receiver battery/voltage, and the time — configurable under
[System Setup — General](../system-setup/general.md).

## Bottom bar

![Bottom bar](../assets/bottombar.png)

A live bar-graph readout of the output channels — the same information as
the [Channels display widget](../displays/index.md#widget-types), always
available regardless of which display screen is active.
