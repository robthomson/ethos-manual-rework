# USB Connection Modes

![USB menu](../assets/usbmenu.png)

Plugging the radio into a computer opens a menu to choose what the USB
connection is used for — mass storage (SD card access), joystick/HID mode
for PC simulators, or a serial/development mode — rather than picking one
automatically.
