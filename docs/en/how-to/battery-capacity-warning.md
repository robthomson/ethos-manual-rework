# Battery Capacity Warning

![Consumption sensor](../assets/how-to-consumption-sensor-edit.png)

Warns based on consumed capacity (mAh) rather than voltage — using a
current sensor (e.g. from a Neuron ESC) and a
[calculated](../model-setup/telemetry.md) consumption sensor, combined
with a logical switch and special function the same way as the [voltage
warning](low-battery-warning.md).
