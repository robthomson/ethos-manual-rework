# In-Flight Adjustable Compensation Curve

![Compensation curve](../assets/how-in-flight-comp-var-comp-curve.png)

Builds an adjustable compensation curve using a
[variable](../model-setup/variables.md) driven in flight (e.g. by a
logical-switch-gated pot), so a compensation curve's shape can be tuned
without re-entering the menus between flights.
