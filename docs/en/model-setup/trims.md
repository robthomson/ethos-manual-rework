# Trims

![Trims](../assets/model-trims.png)

Configures the behavior of the physical trim controls per model — mode
(off, easy, per-flight-mode, or custom), step size, and instant/cross
trim. Custom elevator trim behavior (e.g. offsetting rather than centering
on a speed-dependent curve) is also configured here.
