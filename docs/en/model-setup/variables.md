# Variables

![Variables](../assets/model-vars.png)

Named numeric variables that store and accumulate a value over time (via a
list of actions), for logic that a mix or curve alone can't express —
e.g. building an in-flight-adjustable compensation curve (see
[How-To](../how-to/in-flight-compensation-curve.md)).
