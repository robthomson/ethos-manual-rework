# Logical Switches

![Logical switches](../assets/model-lsw-menu.png)

Logical switches are computed on/off conditions — comparisons, edge
detection, timers/delays, sticky (latching) behavior — built from other
switches, sources, or values. Once defined, a logical switch can be used
as a condition anywhere a physical switch can (a mix condition, a special
function trigger, and so on).
