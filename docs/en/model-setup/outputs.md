# Outputs

![Outputs](../assets/model-outputs.png)

Outputs is the final stage between the mixer and the physical
servo/motor — endpoint limits, subtrim/centering, reversing, and channel
swap/balance tools live here, applied after everything in
[Mixes](mixes.md).
