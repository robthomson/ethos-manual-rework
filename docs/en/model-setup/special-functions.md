# Special Functions

![Special functions](../assets/model-sf-menu.png)

Special functions trigger an action (play a sound/value, haptic feedback,
lock the touchscreen, jump to a screen, write to logs, force a failsafe
value, and more) when a condition becomes true — the model-level companion
to the radio-wide [Alerts](../system-setup/alerts.md).
