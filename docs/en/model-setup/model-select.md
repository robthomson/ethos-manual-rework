# Model Select

![Model wizard - airplane](../assets/model-modelselect-model-wizard-airplane.png)

Model Select is both the model picker (organized into folders by category)
and the **model creation wizard** — a guided sequence (airframe type, tail
type, aileron/flap count, engine type, receiver) that builds a working set
of baseline mixes for you.

![Model folders](../assets/model-modelselect-folders.png)
![Wizard: tail type](../assets/model-modelselect-model-wizard-tail.png)
![Wizard: channel reassignment](../assets/model-modelselect-model-wizard-ch-reassignment.png)

See the [Tutorials](../tutorials/index.md) for full worked examples of the
wizard for fixed-wing, flying-wing, and helicopter models.
