# Flight Modes

![Flight modes](../assets/model-fm.png)

Flight modes (also called flight phases) let mixes, trims, and curves
switch behavior based on a selected mode — e.g. Normal / Idle Up 1 / Idle
Up 2 on a heli, or Launch / Cruise / Land on a glider.
