# Lua interpret

Ethos obsahuje vestavěný interpret založený na **Lua 5.4.3**, doplněný o:

- základní knihovnu
- knihovnu table
- knihovnu io
- knihovnu os
- knihovnu math

Skripty běží v tomto prostředí bez ohledu na to, zda implementují
[widget displeje](../displays/custom-widgets.md), nebo
[zdroj/úlohu](../model-setup/lua-scripts.md) pro konkrétní model.
