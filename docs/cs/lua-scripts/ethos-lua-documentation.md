# Dokumentace Ethos Lua

Kompletní referenční příručka Ethos Lua API je součástí **Ethos Suite**, v záložce **Lua Development Tools** — jde o autoritativní referenci pro každé volání `system.*`, `lcd.*` a další API dostupné skriptu, udržovanou v souladu s verzí Ethos, se kterou je distribuována.

Informace o instalaci a používání samotné PC aplikace najdete v části [Ethos Suite](../ethos-suite/index.md).
