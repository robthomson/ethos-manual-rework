# X18S

![Kontrola hardwaru X18S](../assets/system-hardware-check-x18s.png)

Odlišnosti od výchozí konfigurace X20S, pro kterou je tato příručka napsána:

- **Úložiště** — ve výchozím stavu interní 8GB eMMC (vedle něj lze doplnit
  externí SD card), stejně jako u X20 Pro/R/RS — viz [Nastavení systému →
  Obecné → Umístění
  úložiště](../system-setup/general.md#storage-location-x18-and-x20-prorrs)
  a [Správce souborů](../system-setup/file-manager.md).
- **Přídavné trimy** — stejně jako X20 Pro/R/RS přidává nad standardní
  čtyři ještě trimovací přepínače **T5** a **T6** — viz
  [Trimy](../model-setup/trims.md#trim-settings).
- **[Kontrola hardwaru](../system-setup/hardware.md#hardware-check)** a
  [inspektor hodnot ADC](../system-setup/hardware.md#adc-value-inspector)
  proto do svých kontrol zahrnují i trimy T5/T6.
