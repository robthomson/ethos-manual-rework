# Začínáme

Než se pustíte do nastavení modelu nebo systému, vyplatí se seznámit se se dvěma
věcmi, které budete používat neustále: s [hlavní
obrazovkou](main-views.md) a se samotným [způsobem
navigace](user-interface-and-navigation.md) (otočný enkodér, klávesy
`ENT`/`RTN` a dotykové ovládání).

- [Hlavní zobrazení](main-views.md) — domovská obrazovka a nabídka připojení USB.
- [Uživatelské rozhraní a navigace](user-interface-and-navigation.md) — úprava
  hodnot, klávesnice na obrazovce a způsob, jakým se v celém prostředí Ethos
  vybírá „zdroj“.
- [Režimy připojení USB](usb-connection-modes.md) — co se změní, když je
  vysílač připojen k počítači.
- [Nouzový režim](emergency-mode.md) — co se stane, pokud dojde k závažné
  chybě na nízké úrovni.
