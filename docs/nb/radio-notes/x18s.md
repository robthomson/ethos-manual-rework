# X18S

![Maskinvaresjekk på X18S](../assets/system-hardware-check-x18s.png)

Forskjeller fra X20S-grunnlaget som denne håndboken er skrevet ut fra:

- **Lagring** — internt 8 GB eMMC som standard (et eksternt SD card kan
  legges til i tillegg), samme som X20 Pro/R/RS — se [Systeminnstillinger →
  Generelt → Lagringsplassering](../system-setup/general.md#storage-location-x18-and-x20-prorrs)
  og [Filbehandler](../system-setup/file-manager.md).
- **Ekstra trim** — som X20 Pro/R/RS legger den til trimbryterne **T5** og
  **T6** i tillegg til de fire standardtrimmene — se
  [Trim](../model-setup/trims.md#trim-settings).
- **[Maskinvaresjekk](../system-setup/hardware.md#hardware-check)** og
  [ADC-verdiinspektøren](../system-setup/hardware.md#adc-value-inspector)
  inkluderer T5/T6-trimmene i kontrollene sine tilsvarende.
