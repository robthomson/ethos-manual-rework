# Komme i gang

Før du går løs på modell- eller systeminnstillinger, er det verdt å bli
fortrolig med de to tingene du vil bruke hele tiden: [hovedskjermen](main-views.md)
og selve [navigasjonsmodellen](user-interface-and-navigation.md)
(rotasjonsenkoderen, `ENT`/`RTN`-tastene og berøringsskjermen).

- [Hovedvisninger](main-views.md) — hjemskjermen og menyen for USB-tilkobling.
- [Brukergrensesnitt og navigasjon](user-interface-and-navigation.md) — redigering
  av verdier, skjermtastaturet og hvordan en «kilde» velges gjennom hele
  Ethos.
- [USB-tilkoblingsmoduser](usb-connection-modes.md) — hva som endres når
  senderen kobles til en PC.
- [Nødmodus](emergency-mode.md) — hva som skjer hvis noe går alvorlig galt
  på lavt nivå.
