# Verktøylinjer

To permanente linjer rammer inn hver skjerm i Ethos, både hjemskjermen og menyene.

## Øvre linje

![Øvre linje](../assets/topbar.png)

Viser, fra venstre mot høyre: navn/ikon for den gjeldende modellen, status for RF-forbindelsen, RSSI, batteri/spenning for sender og mottaker, samt klokken — konfigurerbart under [Systeminnstillinger — Generelt](../system-setup/general.md).

## Nedre linje

![Nedre linje](../assets/bottombar.png)

En sanntidsvisning av utgangskanalene som stolpediagram — samme informasjon som [widgeten Kanaler](../displays/index.md#widget-types), alltid tilgjengelig uavhengig av hvilken skjerm som er aktiv.
