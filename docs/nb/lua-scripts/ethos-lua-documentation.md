# Ethos Lua-dokumentasjon

Den komplette Ethos Lua API-referansen følger med **Ethos Suite**, under
fanen **Lua Development Tools** — dette er den autoritative referansen for
alle `system.*`-, `lcd.*`- og andre API-kall som er tilgjengelige for et skript,
og den holdes synkronisert med den Ethos-versjonen den leveres sammen med.

Se [Ethos Suite](../ethos-suite/index.md) for informasjon om installasjon og bruk av
selve PC-programmet.
