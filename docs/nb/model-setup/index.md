# Modelloppsett

Alt i denne delen lagres **per modell** — bytter du modell, bytter du alt
sammen. Her programmeres modellen i praksis, fra valg av flymal til
mikser, utganger og sikkerhetsbrytere. Nås via **Airplane**-fanen på den
nedre menylinjen (eller `MDL`-tasten) — i motsetning til
[Systeminnstillinger](../system-setup/index.md), som dekker alt som er
felles for alle modeller.

- [Modellvalg](model-select.md) — opprette, velge og organisere modeller.
- [Modellredigering](model-edit.md) — modellens eget navn, type og ikon.
- [Flymoduser](flight-modes.md)
- [Mikser](mixes.md) — kjernen i modellprogrammeringen.
- [Utganger](outputs.md) — endepunkter for servo/motor, subtrim og reversering.
- [Timer](timers.md)
- [Trim](trims.md)
- [RF-system](rf-system.md) — binding av mottaker og oppsett av RF-modul.
- [Kurver](curves.md)
- [Logiske brytere](logical-switches.md)
- [Spesialfunksjoner](special-functions.md)
- [Variabler](variables.md)
- [Trener](trainer.md)
- [Telemetri](telemetry.md) — søk etter sensorer og beregnede sensorer.
- [Sjekkliste](checklist.md)
- [Lua-skript](lua-scripts.md) — Lua-skript og -funksjoner per modell.

For gjennomarbeidede eksempler på programmering av en modell fra start til
slutt, se [Veiledninger](../tutorials/index.md), og for oppgavefokuserte
gjennomganger, [Praktiske guider](../how-to/index.md).
