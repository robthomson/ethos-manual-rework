# X18S

![X18S hardwarecontrole](../assets/system-hardware-check-x18s.png)

Verschillen ten opzichte van de X20S, waarop deze handleiding is gebaseerd:

- **Opslag** — standaard een interne 8GB eMMC (er kan daarnaast een
  externe SD card worden toegevoegd), net als bij de X20 Pro/R/RS — zie
  [Systeeminstellingen → Algemeen →
  Opslaglocatie](../system-setup/general.md#storage-location-x18-and-x20-prorrs)
  en [Bestandsbeheer](../system-setup/file-manager.md).
- **Extra trims** — voegt, net als de X20 Pro/R/RS, de trimschakelaars **T5** en
  **T6** toe naast de standaard vier — zie
  [Trims](../model-setup/trims.md#trim-settings).
- **[Hardwarecontrole](../system-setup/hardware.md#hardware-check)** en
  de [ADC-waarde-inspecteur](../system-setup/hardware.md#adc-value-inspector)
  nemen de trims T5/T6 dienovereenkomstig mee in hun controles.
