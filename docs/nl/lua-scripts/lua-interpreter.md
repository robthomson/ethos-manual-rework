# Lua-interpreter

Ethos bevat een interpreter op basis van **Lua 5.4.3**, geleverd met:

- de basisbibliotheek
- de table-bibliotheek
- de io-bibliotheek
- de os-bibliotheek
- de math-bibliotheek

Scripts worden in deze omgeving uitgevoerd, of ze nu een
[display-widget](../displays/custom-widgets.md) implementeren of een
[bron/taak](../model-setup/lua-scripts.md) per model.
