# Ethos Lua-documentatie

De volledige Ethos Lua API-referentie wordt meegeleverd met **Ethos Suite**, onder
het tabblad **Lua Development Tools** — dat is de gezaghebbende referentie voor
elke `system.*`-, `lcd.*`- en andere API-aanroep die voor een script beschikbaar is,
en blijft synchroon met de Ethos-versie waarmee het wordt meegeleverd.

Zie [Ethos Suite](../ethos-suite/index.md) voor het installeren en gebruiken van de
PC-applicatie zelf.
