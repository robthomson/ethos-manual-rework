# Locaties van voorbeeldscripts

Officiële voorbeeldscripts worden gepubliceerd op
[github.com/FrSkyRC/ETHOS-Feedback-Community](https://github.com/FrSkyRC/ETHOS-Feedback-Community/tree/main/lua)
(met name `/lua/examples/task` en `/lua/examples/source`). De meeste
voorbeelden zijn Lua-widgets (geconfigureerd onder [Schermen
configureren](../displays/custom-widgets.md)); het voorbeeld **`servo`**
demonstreert specifiek een **Systeemtool** — een script dat na
**Info** in het systeemmenu verschijnt in plaats van als displaywidget.

## Een script downloaden

1. Open de bovenstaande repositorylink in een browser en navigeer naar de
   gewenste map en vervolgens naar het bestand `main.lua`.
2. Klik op het bestand om het te bekijken en klik daarna op **Raw**.
3. Klik met de rechtermuisknop op de pagina → **Pagina opslaan als…** en sla
   het bestand op als `main.lua`.
4. Verplaats het naar een map met een passende naam om conflicten met de
   `main.lua` van andere scripts te voorkomen — de naam van de bronmap zelf
   is een logische keuze.

Voor alle andere bestanden die een script nodig heeft (afbeeldingen, enz.):
klik op het bestand, klik op **Download**, klik vervolgens met de
rechtermuisknop en kies **Afbeelding opslaan als…** (of iets vergelijkbaars)
om het samen met het script op te slaan.

Scripts worden geïnstalleerd onder `scripts/` op de SD card/eMMC — zie
[Bestandsbeheer](../system-setup/file-manager.md#top-level-folders).

Zie ook de thread *FrSky ETHOS Lua Script Programming* op rcgroups voor
scripts en discussies uit de community, naast de officiële voorbeelden.
