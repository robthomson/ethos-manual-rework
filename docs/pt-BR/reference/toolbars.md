# Barras de ferramentas

Duas barras permanentes enquadram todas as telas do Ethos, seja a tela inicial ou os menus.

## Barra superior

![Barra superior](../assets/topbar.png)

Exibe, da esquerda para a direita: o nome/ícone do modelo atual, o status do enlace RF, o RSSI,
a bateria/tensão do rádio e do receptor e a hora — configurável em
[Configuração do sistema — Geral](../system-setup/general.md).

## Barra inferior

![Barra inferior](../assets/bottombar.png)

Uma leitura em gráfico de barras ao vivo dos canais de saída — a mesma informação do
[widget de tela Canais](../displays/index.md#widget-types), sempre
disponível independentemente de qual tela esteja ativa.
