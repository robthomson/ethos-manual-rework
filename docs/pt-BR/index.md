# Manual do Ethos

O **Ethos** é o sistema operacional que roda nos rádios da família Ethos da FrSky
(X20S, X20 Pro, X20 Pro AW, X18S e outros). Este manual aborda a configuração de
um modelo a partir do zero, o ajuste das configurações no nível do sistema do rádio,
a criação de telas de telemetria personalizadas e o ambiente de scripts Lua que
funciona sobre tudo isso.

!!! note "Trabalho em andamento"
    Este manual foi reconstruído a partir do zero com base no manual oficial do
    Ethos 1.6.3 e no conjunto de capturas de tela existente. Algumas páginas (Ethos
    Suite, Sistema RF e alguns Guias práticos) estão completas, mas ainda não
    possuem capturas de tela — consulte [Pipeline de capturas de
    tela](contributing/screenshot-pipeline.md) e
    [Contribuindo](contributing/index.md) se quiser ajudar.

## Por onde começar

- Novo no Ethos? Comece com [Primeiros passos](getting-started/index.md) —
  o layout da tela principal e o funcionamento da navegação antes de mexer em
  qualquer configuração.
- Configurando um rádio novo? Veja [Configuração do sistema](system-setup/index.md) para as
  configurações únicas que valem para todo o rádio (calibração de hardware, alertas, bateria).
- Programando um modelo? [Configuração do modelo](model-setup/index.md) aborda mixagens,
  saídas, fases de voo e tudo o mais que é definido por modelo, e os
  [Tutoriais](tutorials/index.md) mostram, de ponta a ponta, a criação de modelos de asa fixa,
  asa voadora e helicóptero.
- Montando uma tela de telemetria? Veja [Telas](displays/index.md).
- Quer resolver uma tarefa específica rapidamente? Consulte os [Guias
  práticos](how-to/index.md).
- Escrevendo ou instalando scripts/widgets Lua? Veja [Scripts Lua](lua-scripts/index.md).

## Rádios abordados

Este manual foi escrito principalmente com base no **X20S**, com as diferenças
específicas de cada rádio (X20 Pro, X20 Pro AW, X18S) indicadas em
[Notas do rádio](radio-notes/index.md) onde a interface divergir.
