# Interpretador Lua

O Ethos incorpora um interpretador baseado no **Lua 5.4.3**, empacotado com:

- a biblioteca básica
- a biblioteca table
- a biblioteca io
- a biblioteca os
- a biblioteca math

Os scripts são executados nesse ambiente, tanto ao implementar um
[widget de tela](../displays/custom-widgets.md) quanto uma
[fonte/tarefa](../model-setup/lua-scripts.md) por modelo.
