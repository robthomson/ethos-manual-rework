# Documentação Lua do Ethos

A referência completa da API Lua do Ethos é distribuída junto com o **Ethos Suite**, na
aba **Lua Development Tools** — essa é a referência oficial para
cada chamada `system.*`, `lcd.*` e demais chamadas de API disponíveis a um script,
mantida em sincronia com a versão do Ethos com a qual é distribuída.

Consulte [Ethos Suite](../ethos-suite/index.md) para instalar e utilizar o
próprio aplicativo de PC.
