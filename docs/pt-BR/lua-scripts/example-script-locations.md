# Localização dos scripts de exemplo

Os scripts de exemplo oficiais são publicados em
[github.com/FrSkyRC/ETHOS-Feedback-Community](https://github.com/FrSkyRC/ETHOS-Feedback-Community/tree/main/lua)
(em especial `/lua/examples/task` e `/lua/examples/source`). A maioria dos
exemplos são widgets Lua (configurados em [Configurar
telas](../displays/custom-widgets.md)); o exemplo **`servo`**
demonstra especificamente uma **Ferramenta de Sistema** — um script que aparece após
**Info** no menu System, em vez de como um widget de tela.

## Baixando um script

1. Abra o link do repositório acima em um navegador e navegue até a
   pasta e, em seguida, até o arquivo `main.lua` desejado.
2. Clique no arquivo para visualizá-lo e depois em **Raw**.
3. Clique com o botão direito na página → **Salvar página como…**, salvando-a como `main.lua`.
4. Para evitar conflito com o `main.lua` de outros scripts, mova-o para uma
   pasta com nome correspondente — o próprio nome da pasta de origem é uma
   escolha sensata.

Para quaisquer outros arquivos de que o script precise (imagens, etc.): clique no arquivo, clique
em **Download** e, em seguida, clique com o botão direito e escolha **Salvar imagem como…** (ou equivalente) para
salvá-lo junto com o script.

Os scripts são instalados na pasta `scripts/` do SD card/eMMC — consulte [Gerenciador
de arquivos](../system-setup/file-manager.md#top-level-folders).

Veja também o tópico *FrSky ETHOS Lua Script Programming* no rcgroups para
scripts e discussões da comunidade além dos exemplos oficiais.
