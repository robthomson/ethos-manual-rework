# Ethos Benutzerhandbuch

**Ethos** ist das Betriebssystem, das auf den Sendern der Ethos-Familie von FrSky
(X20S, X20 Pro, X20 Pro AW, X18S und weitere) läuft. Dieses Handbuch behandelt die
Einrichtung eines Modells von Grund auf, die Konfiguration der senderweiten
Systemeinstellungen, den Aufbau eigener Telemetrieanzeigen sowie die
Lua-Skriptumgebung, die auf all dem aufsetzt.

## Wo anfangen

- Neu bei Ethos? Beginnen Sie mit [Erste Schritte](getting-started/index.md) —
  dem Aufbau der Hauptansicht und der Funktionsweise der Navigation, bevor Sie
  Einstellungen ändern.
- Sie richten einen neuen Sender ein? Siehe [System einrichten](system-setup/index.md)
  für die einmaligen, senderweiten Einstellungen (Hardware-Kalibrierung, Alarme, Akku).
- Sie programmieren ein Modell? [Modell-Einstellung](model-setup/index.md) behandelt
  Mischer, Ausgänge, Flugphasen und alles Weitere, was pro Modell gespeichert wird, und
  die [Programmier-Beispiele](tutorials/index.md) führen Schritt für Schritt durch den
  Aufbau von Flächenflugzeugen, Nurflüglern und Hubschraubern.
- Sie erstellen einen Telemetriebildschirm? Siehe [Bildschirme konfigurieren](displays/index.md).
- Sie möchten eine bestimmte Aufgabe schnell lösen? Sehen Sie im Abschnitt
  [Gewusst wie](how-to/index.md) nach.
- Sie schreiben oder installieren Lua-Skripte bzw. Widgets? Siehe [Lua-Skripte](lua-scripts/index.md).

## Behandelte Sender

Dieses Handbuch bezieht sich in erster Linie auf den **X20S**; senderspezifische
Abweichungen (X20 Pro, X20 Pro AW, X18S) werden in den
[Senderhinweisen](radio-notes/index.md) dort aufgeführt, wo die Bedienoberfläche abweicht.
