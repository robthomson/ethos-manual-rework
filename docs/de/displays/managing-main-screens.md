# Hinzufügen benutzerdefinierter Widgets

Bei benutzerdefinierten Widgets handelt es sich in der Regel um LUA-Skripte, die in der Regel in Form einer einzigen „main.lua“-Datei vorliegen, die üblicherweise in einem Unterordner mit einem Namen aufbewahrt wird, der auf ihre Funktionalität hinweist.

Dieser Unterordner sollte in den Ordner „scripts“ auf der SD-Karte oder eMMC kopiert werden. Das Widget wird beim Starten automatisch registriert. Mit Bildschirmen konfigurieren können Sie das Widget dann, wie jedes andere konfigurieren.
