# Zusätzliche Anzeigen

![Konfigurationsoptionen für Bildschirme](../assets/display-screen-config-options.png)

Das Standardmodell verfügt über einen Bildschirm (eine Modellgrafik sowie drei
Timer-Widgets), es werden jedoch insgesamt bis zu **acht** Bildschirme
unterstützt. Tippen Sie auf das **+** neben „Screen1“, um einen weiteren
hinzuzufügen:

- Wählen Sie aus **15** Layouts, darunter zwei spezielle Startbildschirm-Layouts
  und eine Vollbild-Option mit Platz für bis zu 9 Widgets — die Konfiguration
  erfolgt genau wie beim ersten Bildschirm.
- Bildschirme können über ihren eigenen Bearbeitungsdialog verschoben oder
  gelöscht werden (tippen Sie dazu auf Screen1, Screen2 usw.).

## Praxisbeispiel

![Hauptansicht](../assets/display-main-view.png)

Ein typisches Layout: links die Modellgrafik (konfiguriert unter [Model Edit →
Picture](../model-setup/model-edit.md)), rechts untereinander die
Empfängerakkuspannung, RSSI und ein Status-Widget „Throttle ACTIVE“ (ein von der
Community erstelltes Lua-Widget aus dem rcgroups-Thread *FrSky - ETHOS Lua Script
Programming*). Durch Antippen eines Widgets wird dessen Konfiguration geöffnet
oder direkt zur Hauptfunktion „Bildschirme konfigurieren“ gesprungen.

## Optionen auf Bildschirmebene

Über die einzelnen Widgets hinaus verfügt jeder Bildschirm über eigene
Einstellungen — Rastergröße des Layouts, Hintergrund und die Festlegung, welche
Bildschirme in den `PAGE`-Durchlauf einbezogen werden.

Siehe [Anzeigen](index.md) für die Widgets selbst und [Benutzerdefinierte
Widgets](custom-widgets.md) für das Hinzufügen von Lua-Widgets über den
integrierten Umfang hinaus.
