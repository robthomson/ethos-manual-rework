# X18S

![X18S Hardware-Check](../assets/system-hardware-check-x18s.png)

Unterschiede zur X20S-Basis, auf die sich dieses Handbuch bezieht:

- **Speicher** — standardmäßig ein interner 8-GB-eMMC-Speicher (zusätzlich
  kann eine externe SD card eingesetzt werden), wie beim X20 Pro/R/RS — siehe
  [Systemeinstellungen → Allgemein →
  Speicherort](../system-setup/general.md#storage-location-x18-and-x20-prorrs)
  und [Dateimanager](../system-setup/file-manager.md).
- **Zusätzliche Trimmungen** — wie beim X20 Pro/R/RS gibt es über die vier
  Standardtrimmungen hinaus die Trimmschalter **T5** und **T6** — siehe
  [Trimmung](../model-setup/trims.md#trim-settings).
- **[Hardware-Check](../system-setup/hardware.md#hardware-check)** und der
  [ADC-Werteanzeiger](../system-setup/hardware.md#adc-value-inspector)
  berücksichtigen entsprechend auch die Trimmungen T5/T6.
