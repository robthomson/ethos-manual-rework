# X18S

![X18S Hardware-Check](../assets/system-hardware-check-x18s.png)

Unterschiede zum X20S, der diesem Handbuch als Grundlage dient:

- **Speicher** — standardmäßig ein interner 8-GB-eMMC-Speicher (zusätzlich kann
  eine externe SD card verwendet werden), wie beim X20 Pro/R/RS — siehe
  [System-Einstellungen → Allgemein →
  Speicherort](../system-setup/general.md#storage-location-x18-and-x20-prorrs)
  und [Dateimanager](../system-setup/file-manager.md).
- **Zusätzliche Trimmungen** — wie beim X20 Pro/R/RS kommen zu den vier
  Standardtrimmungen die Trimmschalter **T5** und **T6** hinzu — siehe
  [Trimmungen](../model-setup/trims.md#trim-settings).
- **[Hardware-Check](../system-setup/hardware.md#hardware-check)** und die
  [ADC-Wert-Anzeige](../system-setup/hardware.md#adc-value-inspector)
  berücksichtigen entsprechend auch die Trimmungen T5/T6.
