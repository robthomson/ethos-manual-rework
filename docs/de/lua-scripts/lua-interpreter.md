# Lua-Interpreter

Ethos enthält einen Interpreter auf Basis von **Lua 5.4.3**, der Folgendes umfasst:

- die Basisbibliothek
- die table-Bibliothek
- die io-Bibliothek
- die os-Bibliothek
- die math-Bibliothek

Skripte werden in dieser Umgebung ausgeführt – unabhängig davon, ob sie ein
[Anzeige-Widget](../displays/custom-widgets.md) oder eine modellspezifische
[Quelle bzw. Aufgabe](../model-setup/lua-scripts.md) implementieren.
