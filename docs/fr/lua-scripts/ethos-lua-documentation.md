# Documentation Lua d'Ethos

La référence complète de l'API Lua d'Ethos est fournie avec **Ethos Suite**,
dans son onglet **Lua Development Tools** — il s'agit de la référence de
référence pour chaque appel `system.*`, `lcd.*` et autres API disponibles pour
un script, maintenue en accord avec la version d'Ethos avec laquelle elle est
distribuée.

Voir [Ethos Suite](../ethos-suite/index.md) pour l'installation et l'utilisation
de l'application PC elle-même.
