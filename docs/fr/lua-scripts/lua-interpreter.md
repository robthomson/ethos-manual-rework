# Interpréteur Lua

Ethos intègre un interpréteur basé sur **Lua 5.4.3**, fourni avec :

- la bibliothèque de base
- la bibliothèque table
- la bibliothèque io
- la bibliothèque os
- la bibliothèque math

Les scripts s'exécutent dans cet environnement, qu'ils implémentent un
[widget d'affichage](../displays/custom-widgets.md) ou une
[source/tâche](../model-setup/lua-scripts.md) propre au modèle.
