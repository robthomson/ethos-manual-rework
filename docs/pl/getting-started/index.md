# Pierwsze kroki

Zanim przejdziesz do ustawień modelu lub systemu, warto oswoić się z dwoma
elementami, z których będziesz korzystać nieustannie: [ekranem
głównym](main-views.md) oraz samym [modelem
nawigacji](user-interface-and-navigation.md) (enkoder obrotowy, klawisze
`ENT`/`RTN` oraz dotyk).

- [Widoki główne](main-views.md) — ekran główny i menu połączenia USB.
- [Interfejs użytkownika i nawigacja](user-interface-and-navigation.md) — edycja
  wartości, klawiatura ekranowa oraz sposób wybierania „źródła” w całym
  Ethos.
- [Tryby połączenia USB](usb-connection-modes.md) — co się zmienia, gdy
  nadajnik zostanie podłączony do komputera.
- [Tryb awaryjny](emergency-mode.md) — co się dzieje, gdy coś poważnie
  zawiedzie na niskim poziomie.
