# Dokumentacja Ethos Lua

Pełna dokumentacja API Ethos Lua jest dołączona do **Ethos Suite**, w zakładce
**Lua Development Tools** — jest to autorytatywne źródło informacji o
każdym wywołaniu API dostępnym dla skryptu (`system.*`, `lcd.*` i pozostałych),
utrzymywane w zgodności z wersją Ethos, wraz z którą jest dostarczane.

Informacje o instalacji i korzystaniu z samej aplikacji PC znajdziesz w rozdziale
[Ethos Suite](../ethos-suite/index.md).
