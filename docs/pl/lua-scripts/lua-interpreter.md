# Interpreter Lua

Ethos zawiera wbudowany interpreter oparty na **Lua 5.4.3**, dostarczony wraz z:

- biblioteką podstawową
- biblioteką table
- biblioteką io
- biblioteką os
- biblioteką math

Skrypty działają w tym środowisku niezależnie od tego, czy implementują
[widget wyświetlacza](../displays/custom-widgets.md), czy przypisane do modelu
[źródło/zadanie](../model-setup/lua-scripts.md).
