# Primeros pasos

Antes de adentrarse en los ajustes del modelo o del sistema, conviene familiarizarse
con los dos elementos que utilizará constantemente: la [pantalla
principal](main-views.md) y el propio [modelo de
navegación](user-interface-and-navigation.md) (el selector rotatorio, las
teclas `ENT`/`RTN` y la pantalla táctil).

- [Pantallas Principales](main-views.md) — la pantalla de inicio y el menú de conexión USB.
- [Interfaz de usuario y Navegación](user-interface-and-navigation.md) — la edición
  de valores, el teclado virtual y cómo se selecciona una «fuente» en todo
  Ethos.
- [Modos de conexión USB](usb-connection-modes.md) — qué cambia cuando la
  radio se conecta a un PC.
- [Modo de emergencia](emergency-mode.md) — qué ocurre si algo falla
  gravemente a bajo nivel.
