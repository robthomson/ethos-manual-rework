# Añadir widgets personalizados

Los widgets personalizados suelen ser lua scripts que normalmente vienen en forma de un único archivo 'main.lua', que normalmente se guarda en una subcarpeta con un nombre que sugiere su funcionalidad. Esta subcarpeta debe copiarse en la carpeta "scripts" de la tarjeta SD o eMMC. El widget se registrará automáticamente al encenderse la emisora. Seguidamente, se pueden utilizar sus pantallas de configuración para configurar el widget como cualquier otro.
