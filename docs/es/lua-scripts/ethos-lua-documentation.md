# Documentación Lua de Ethos

La referencia completa de la API Lua de Ethos viene incluida en **Ethos Suite**, en su pestaña **Herramientas de desarrollo Lua** (Lua Development Tools): esa es la referencia oficial de todas las llamadas `system.*`, `lcd.*` y demás llamadas de la API disponibles para un script, y se mantiene sincronizada con la versión de Ethos con la que se distribuye.

Consulte [Ethos Suite](../ethos-suite/index.md) para instalar y utilizar la propia aplicación de PC.
