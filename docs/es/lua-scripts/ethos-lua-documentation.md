# Documentación de Lua para Ethos

La referencia completa de la API Lua de Ethos se distribuye con **Ethos Suite**, en su pestaña **Lua Development Tools**: esa es la referencia autorizada de todas las llamadas `system.*`, `lcd.*` y demás llamadas de la API disponibles para un script, y se mantiene sincronizada con la versión de Ethos con la que se distribuye.

Consulte [Ethos Suite](../ethos-suite/index.md) para instalar y utilizar la propia aplicación de PC.
