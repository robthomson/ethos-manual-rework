# Límites de configuración de los Lua scripts

- 2MB para mapas de bits (un bitmap a pantalla completa en la X20 consume 768K)

- 2MB para scripts Lua (es una cantidad grande)

Evite usar demasiada ram para las imágenes. Se sugiere a los usuarios cargar un bitmap SÓLO cuando sea necesario. Luego mantenerlo en la memoria para siguientes usos, para evitar múltiples lecturas de la tarjeta SD o eMMC.
